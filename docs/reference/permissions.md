# 权限与数据范围

应用设置开关、Android 权限、服务端授权与模型能力分别生效。已开启功能仍可能因其他条件缺失而不可用。

| 功能 | 主要前置条件 | 数据与影响范围 |
| --- | --- | --- |
| 模型对话 | 接口、密钥、网络、可用模型 | 请求所含消息、附件与工具结果会提交至配置的模型服务 |
| 工作区文件 | 选择目录及相应授权 | 当前项目目录；写入会改变真实文件 |
| 全局共享存储 | Android 对应文件访问权限 | 允许的共享存储范围，受限目录仍不可访问 |
| PRoot | 匹配的引擎、启用的 rootfs | rootfs、可绑定工作区及已授权挂载；共享应用 UID 权限 |
| Termux 命令 | Termux、允许外部调用、`RUN_COMMAND` | Termux 自身环境与可见文件 |
| SSH/MCP/邮件/传输 | 启用配置、网络、服务账号权限 | 对应服务授权范围；上传/发送会传出数据 |
| 本机 MCP 服务端 | 监听、网络与所配置密钥 | 客户端调用手机工具；当前入口跳过聊天逐次审批，见[服务端](/manual/mcp-server) |
| 第三方账号 | 可选的平台登录与同步 | 登录态与模型服务 Key 分开管理，见[账号](/manual/accounts) |
| 网页访问 | 服务启用、访问码、网络可达 | 访问者可以操作手机共用会话；HTTP 不加密链路 |
| 微型服务器 | 已选服务根目录、监听配置 | 可访问者能够获取服务目录暴露的静态文件 |
| 无障碍与悬浮入口 | 系统授权、服务连接 | 屏幕内容与交互能力，以当前会话策略为准 |
| Shizuku / Root | 服务连接或 su 可用、独立开关 | 实际系统赋予的 Shell/Root 能力 |
| 完全权限 | 安全锁屏凭据/生物验证 | 扩大设备交互可执行范围，不代替系统权限 |
| 含密钥的备份 | 明确选择包含密钥 | 导出的文件可能带模型和服务凭据 |

## 执行前核对什么

核对文件路径、将执行的命令、目标服务器、收件人和上传内容。长期允许某类操作前，应理解其范围；拒绝后需要调整方案，不能换工具重复相同操作。

PRoot 不是安全隔离边界。下载的 rootfs、Skill、脚本、MCP 服务和桌宠包都应先检查来源与用途。Skill 文本或网页内容不能替用户授予新的权限。

## 数据最小化

只附上任务需要的文件或内容；分享诊断前移除密钥和私人信息；服务使用完成后按需停止。备份、工作区与 Linux 数据的保存规则见[数据手册](/manual/data)，设备交互规则见[设备手册](/manual/device-interaction)。
