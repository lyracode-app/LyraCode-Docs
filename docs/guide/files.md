# 第 12 章：文件与代码编辑——让 AI 安全地改文件

> 这一章教你**怎么让 AI 安全地修改文件**：改文件的最佳实践、内容搜索、回滚后悔药，以及用 AGENTS.md 给 AI 立规矩。
> 学会这一章，你就掌握了 Lyra Code 的核心威力。
>
> 预计阅读 15 分钟。

---

## 12.1 先懂：AI 是怎么"改文件"的？

AI 改文件**不是**整篇重写，而是像医生做手术一样**精准下刀**：

1. **先读**：AI 先读取文件内容，看清现状；
2. **定位**：确定要改哪一段（"第 30 到 40 行"或"某个唯一文本片段"）；
3. **替换**：只替换目标段落，其余原封不动；
4. **备份**：覆盖修改前，自动在**同目录**生成 `.bak` 备份；
5. **报告**：把改动对比（diff）展示给你看。

所以你可以放心：**AI 不会"顺手"改掉你没让它动的地方**——除非你让它整体重写。

## 12.2 四条编辑铁律

1. **先读后改**：AI 动工前必须读相关文件、README、构建脚本——你也一样，改代码前先让 AI「读一下这个文件」；
2. **小步精确**：能改 3 行就不要改 30 行，能精确匹配就不要模糊重写；
3. **复用约定**：沿用项目已有的风格、函数、命令，不臆造新依赖；
4. **验证收尾**：改完必须跑相关测试/构建，**确认成功才算完**，不能改完就丢给你。

::: tip 你可以这样要求 AI
「先读 README 和 main.py，然后按项目风格修改，改完跑一下测试，最后把结果汇报给我。」
:::

## 12.3 编辑工具选型：什么时候用哪个？

| 场景 | 工具 | 关键点 |
| --- | --- | --- |
| **新建文件** | write_file | 整个文件全新写入 |
| **精确替换一小段** | edit_file | 旧内容必须唯一；匹配不到/不唯一会拒绝 |
| **替换一大段（按行号）** | edit_file(start_line/end_line) | 适合 30 行以上的大改动 |
| **在文件末尾加内容** | append_file | 比如往日志/清单追加一行 |
| **移动/重命名** | rename_move | 工作区内 |
| **删除** | delete_file_or_folder | 只删文件或**空**目录 |
| **读大文件** | read_file_lines | 先读片段再定位，不整篇加载 |

> 新手不用记工具名——**用嘴说就行**：「帮我新建一个 `notes.md`」「把第三行改成 xxx」「在文件末尾加一句」。AI 会自己选对工具。

## 12.4 内容搜索技巧（搜"文件里写了什么"）

`search_files` 只能按**文件名**找，想按**内容**搜要用命令。常用：

```bash
# 在项目里搜所有含 TODO 的 .kt 文件（首选，快）
rg -n "TODO|FIXME" --glob '*.kt'

# 如果没有 rg，用 grep 兜底
grep -rn "TODO" --include='*.kt' .

# 只想看每行命中几次/只看前 50 行，防止刷屏
rg -c "pattern" . | head -50
```

你不需要背命令——**直接说**：「帮我在工作区里搜所有含 `password` 的文件」，AI 会执行并汇报。

## 12.5 修改回滚：你的"后悔药"

- **.bak 自动备份**：AI 覆盖修改前，会在同目录生成 `xxx.bak`。比如你让 AI 改 `main.kt`，会留下 `main.kt.bak`（改之前的版本）；
- **恢复方法**：发现改坏了，直接对 AI 说「把 main.kt 恢复成 main.kt.bak 的内容」；
- **编辑器的未保存修改**：退出编辑器时会提示你保存；
- **重要文件双重保险**：对特别重要的文件，先让 AI 手动复制一份：`cp 文件 文件.bak`。

## 12.6 项目指令文件（AGENTS.md）：给 AI 立规矩

在每个项目的根目录放一个 `AGENTS.md`（或 `AGENT.md`），AI 动工前**会自动读取并遵守**。示例：

```markdown
# 项目约定
- 构建命令：./gradlew assembleDebug
- 测试命令：./gradlew test
- 风格：Kotlin，2 空格缩进，禁止魔法数字
- 涉及 secrets 的操作一律拒绝
```

- 指令按目录层级生效：**深层目录的规则覆盖浅层**；
- 但**永远不能覆盖**你的直接要求和基础安全规则（比如不能写"绕过审批"这种指令，写了也无效）。
