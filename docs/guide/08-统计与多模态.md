## 14. 用量统计与设备诊断

### 14.0 什么是「用量统计」？——看清你的钱花在哪

和 AI 对话是按"Token"计费的（Token 可以粗浅理解为"字数单位"）。用量统计就是帮你**看清每一分钱花在哪**：

- 统计维度：对话数、消息数、**你输入的 Token**、**AI 输出的 Token**；
- 连 AI 的思考过程（思维链）、工具调用、读文件、命令输出、重复上下文都算；
- **离线估算**：不联网、不把数据发给第三方，纯本地计算；
- 支持按 **日 / 周 / 月 / 年 / 总计 / 历史区间** 查看。

### 14.1 用量统计有什么用？

- **算成本**：对比不同模型/提示词哪个更费钱，优化选择；
- **找"偷吃"**：看 Agent 任务里工具调用和文件读取占了多少 Token——如果某次任务特别烧钱，多半是上下文膨胀了（比如让 AI 反复读大文件），可以优化提示词。

::: tip 新手提示
刚上手不用天天看。等你有付费焦虑或想对比模型时再来查。
:::

### 14.2 设备诊断：给手机"体检"

Lyra Code 可以读取你手机的信息，用于排查问题：

| 功能 | 能看到什么 | 什么时候用 |
| --- | --- | --- |
| 手机信息页 | 厂商、型号、Android 版本、CPU、内存、存储、屏幕、网络、蓝牙、电池 | 想了解手机配置 |
| 硬件检查 Agent | 用 AI 分析手机信息、排查故障、对比硬件 | 手机出问题，问 AI「帮我看看哪里不对」 |
| 应用列表 | 已安装应用（包名、版本、签名） | 找某个 App 的完整包名 |

::: warning 说明
这些信息用于**排查与合理推测**，不能当作手机真伪的**绝对证明**。想要更深入的系统级诊断，可以配合 Shizuku 跑 `dumpsys` / `pm` 命令（见第 4 章）。
:::

## 15. 多模态、主题与内容渲染

### 15.1 图片与媒体：让 AI"看得见"

- **发图给 AI**：上传图片、拍照上传，支持**裁剪、旋转、画笔标注、马赛克标注**（标出重点再问 AI）；
- **看 AI 的图**：AI 返回的图片/视频支持缩略图、预览、保存；
- 附件会以多模态内容或提取文本形式给到 AI——具体取决于你当前用的模型支不支持看图（不支持就让它描述文字内容）。

> 新手玩法：「拍一张路由器背面，问 AI 上面写的管理地址是什么。」（前提：模型支持视觉）

### 15.2 渲染能力：聊天里的花活

- **Markdown**：加粗、列表、表格都正常显示；
- **代码高亮**：代码块自动上色；
- **数学公式**：LaTeX 公式本地渲染（比如 `$E=mc^2$`）；
- **图片直显**：AI 返回的图片链接/Data URL 可直接预览。

### 15.3 主题与显示设置

| 设置 | 说明 | 新手建议 |
| --- | --- | --- |
| 主题模式 | 浅色 / 深色 / 跟随系统 | 跟随系统最省心 |
| Material You | 动态配色（只调颜色不动布局） | 喜欢就开 |
| 字体大小 | 实时预览，可跟随系统或自定义 | 按眼睛舒服程度调 |
| 刷新率 | 系统智能 / 30 / 60 / 90 / 120 Hz | 默认「系统智能」即可，最终取决于屏幕硬件 |

### 15.4 新手 FAQ

**Q：为什么 AI 说"我看不了这张图"？**
A：你当前用的模型不支持视觉输入。换一个支持图片的模型（如 GPT-4o、Gemini、Claude 系列）即可。

**Q：用量统计的数字准吗？**
A：是本地估算，和模型服务商账单可能有小误差，但足够用来对比和监控趋势。

**Q：诊断信息会不会泄露隐私？**
A：这些信息只在你主动让 AI 分析时被读取，存在本地，不会自动上传。
