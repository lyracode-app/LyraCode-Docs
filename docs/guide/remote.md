# 第 14 章：远程服务——让 AI 帮你连服务器、管邮件、传文件

> 这一章介绍 Lyra Code 的「远程能力」：连接你自己的服务器、邮箱、网盘、FTP。
> 用大白话讲：**让你手机上的 AI 能"遥控"你别的电脑和账号**。
> （MCP 请见[第 15 章](/guide/mcp)。）
>
> 预计阅读 20 分钟。

---

## 14.1 先懂：远程集成能干什么？（场景举例）

- **SSH**：你有台云服务器（Linux），想让 AI 上去查看日志、重启服务、部署项目；
- **邮件**：你有 QQ/163/Gmail 邮箱，想让 AI 读未读邮件、帮你写回信草稿；
- **WebDAV**：你有坚果云/Nextcloud 等网盘，想让 AI 上传/下载文件、自动备份；
- **FTP/SFTP**：你有传统 FTP 空间，让 AI 传文件上去。

所有远程功能遵循**同一套安全模式**：

> **先列账号，再操作。** 每次操作都要你确认。凭据只保存在本机。

## 14.2 账号管理总则

- 所有远程配置（SSH、邮件、WebDAV、FTP）都通过 App 的**「配置管理」**维护；
- 添加账号时，**缺失的密码、Key、私钥必须由你提供**——AI 不会凭空捏造；
- 身份不明确时，AI 会**先列出已有账号**让你确认，再操作；
- 修改过密码后，旧账号 id 会失效，需要重新列一遍。

::: tip 怎么添加账号？
两种方式任选：
1. **自己填**：设置页 → 配置管理 → 添加 SSH/邮件/WebDAV…，手动填主机、账号、密码；
2. **让 AI 填**：直接对 AI 说「帮我添加一个 WebDAV 账号，地址 xxx，用户名 xxx，密码 xxx」，AI 会走配置流程（密码只保存在本机）。
:::

## 14.3 SSH：连上你的服务器

**是什么**：SSH 是连接 Linux/Windows 服务器的标准方式。配好后，AI 可以像在手机本地一样在服务器上执行命令。

**配置需要**：服务器地址、端口（默认 22）、用户名、密码（或私钥）；支持密码和密钥认证。

**使用示例**：

> 帮我看一下服务器上的磁盘占用：ssh_exec 执行 `df -h`

**安全要点（新手必读）**：

- 每次执行命令都要确认；
- AI 在远程**装软件、改配置前**，会先检查服务器的系统、CPU、内存、磁盘、权限；
- 读日志先看大小和行数，只读一小段（`ls -lh app.log && tail -50 app.log`）；
- 不要跑交互式程序（`vim`、`top`、嵌套 ssh）；
- 不要把「安装、修改、启动」串成一条命令，让 AI 分步做、你逐步确认。

::: warning 注意
对强交互型的命令支持不佳，千万不要运行复杂强交互的命令。（你执行了也并不会怎么样……）
:::

## 14.4 邮件（IMAP / SMTP）：让 AI 帮你收发信

**是什么**：
- **IMAP**：读取邮箱（收件箱、草稿箱……）；
- **SMTP**：发送邮件。

应用从 **3.5.0 版本**开始支持连接 SMTP 和 IMAP 邮件服务器，你可以让 AI 操作你的邮件，辅助处理。

**典型用法**：让 AI 列出未读邮件 → 提取重点 → 帮你起草回信 → 你审阅后发送。

**工作流程**：

```text
列出账号 → 列出文件夹 → 列出邮件 → 读某封邮件 / 存草稿 / 发送
```

**安全要点**：

- **读信不改状态**：AI 读邮件不会把它标记为"已读"；
- **正文只有文字**：图片、附件字节不会被 AI 读取（防止泄露）；
- **附件进隔离区**：下载的附件放在隔离目录，**AI 不读内容**——请先自己用杀毒软件扫描再打开；
- **发送要单独确认**：每次 `send_email` 都要你点确认，且不会自动重试可能重复的邮件；**邮件发送确认是强制执行**，不会由于开启无审批模式就会自动同意；
- **更稳妥的方式**：让 AI **存草稿**（存到草稿箱），你审阅后在邮箱里手动点发送；
- **别回复自己**：不要回复"当前配置账号自己发来的邮件"。

::: tip 注意
部分邮件商不允许直接使用密码登录，而是使用**授权码**（应用专用密码），且此功能需要额外开启才能在外部应用连接。
:::

## 14.5 WebDAV：把网盘当"云备份"

**是什么**：WebDAV 是一种网络文件协议，坚果云、Nextcloud、Cloudreve、123 云盘等都支持（绝大部分自建和第三方 WebDAV 服务器）。配好后，AI 可以把网盘当作一个远程文件夹。

**典型用法**：

- 上传/下载文件：`webdav_upload_from_workspace` / `webdav_download_to_workspace`；
- **自动云备份**：把 Lyra Code 的备份直接导出到 WebDAV（见[第 20 章「备份与迁移」](/guide/backup)）；
- 浏览网盘目录：`webdav_list`（推荐用它看目录，比搜索更直观）。

## 14.6 FTP / FTPS / SFTP：传统文件传输

**是什么**：老牌的文件传输协议。适合连接到一些旧服务器、虚拟主机、网站运维。

- 支持目录列举、搜索、上传、下载；
- 几乎所有的服务器和 PC 设备都支持，对网站运维者很有帮助；
- 凭据、被动模式等参数在配置里维护（连不上时优先检查这些）。

## 14.7 自然语言配置管理：用中文指挥 AI

你不需要记住任何配置菜单，直接说人话，例如：

```text
添加一个 WebDAV 账号：https://dav.example.com，用户名 alice，密码 ********
把 SSH 服务器「nas」的密钥更新为新的私钥内容
禁用 FTP 账号 server-02
```

AI 会先列出当前配置确认身份，再执行变更（并给你确认）。

## 14.8 新手 FAQ

**Q：这么多远程功能，我必须全部配置吗？**
A：不用。用到哪个配哪个。纯聊天用户什么都不用配。

**Q：账号密码存在哪里？安全吗？**
A：存在手机本地，备份默认不导出密钥。比存在云端笔记里安全得多，但仍建议设置手机锁屏。

**Q：AI 能偷看我的邮件内容吗？**
A：只有你让它读时它才读，且读信不会改状态、附件不进对话。发送行为每次都要你确认。

**Q：连不上服务器/邮箱？**
A：按顺序检查：① 账号密码对不对；② 端口和加密方式（SSL/STARTTLS）对不对；③ 网络通不通；④ 修改密码后重新列一下账号。
