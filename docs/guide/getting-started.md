# 快速开始

## 设备要求

在使用本应用前，你需要一台搭载 **Android 8.0（API 26）及以上版本**的 Android 设备，应用无法在低于 Android 8.0 的设备上使用。

此外，请确保设备至少有 **200MB 的剩余存储空间**和 **400MB 的空余内存**。

## 安装受限怎么办

本应用**不存在恶意代码**。如果你的安装器反馈有病毒拦截了安装，请**截图详细内容反馈给开发者**。

- **中国大陆发售的设备**：反馈「无备案」是正常的，允许安装即可。
- **非国行设备**：谷歌官方会在 2027 年开始全面推行新的侧载策略，你在安装本软件时可能遭到 Google Play 安全框架的拦截，需要参考此页面进行高级流程才能安装：<https://android-developers.googleblog.com/2026/03/android-developer-verification.html>

**简要操作流程：**

1. 在系统设置中**启用开发者模式**。
2. 确认你没有被胁迫或诱导开启：谷歌会有一个环境检查，确保这个过程不是被恶意启动。
3. **重启设备并重新认证**：拦截远程控制以及监视行为。
4. **保护性时间**：等待 24 小时后进行设备 PIN 码或生物识别认证。
5. **安装应用**：以上步骤完成后即可正常安装。

如果谷歌后续有新的侧载政策变更或流程变化，本应用会考虑进行开发认证以简化安装流程。

## 使用 ADB 安装

你也可以使用 **ADB 命令直接安装**，这个方法可以绕过系统安装器，无论是国行还是非国行设备：

```
adb install -r lyra-code.apk
```
