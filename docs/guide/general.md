# 通用功能

本条目会指导你如何在 Lyra Code 查看与设置基础通用功能。

## AI Agent 工具

在 **设置 → AI Agent 工具** 页，你可以：

- 查看所有 Agent 工具
- 设置是否启用

**主动 Agent**：部分 Agent 工具是由 AI 执行并**主动反馈**，并非依赖用户手动操作。例如**向用户追问**这个 Agent 工具就具有主动性，因为它是基于 AI 的思维方式决定是否调用。

## 数据备份

你可以在**数据导出导入页**导出指定数据文件。导出备份支持**自定义导出内容**。

支持的备份内容包括：

- 个人资料
- 对话历史
- 模型配置
- MCP、SSH、WebDAV、FTP/FTPS/SFTP 配置
- 系统提示词
- Skills 等

支持的备份方式：

- 本地 zip 备份
- WebDAV 云备份
- 不包含 API Key 的安全导出
- 包含密钥的完整迁移备份

**导入备份**一共两种模式，分为**补充导入**和**覆盖导入**：

- **补充导入**：在现有配置基础上新增。应用会识别备份包内是否有目前不存在的配置并新增，同配置会进行去重，适合任意情况下的备份导入。
- **覆盖导入**：移除已有的所有配置，以备份包内的数据作为新配置，仅适合将数据迁移到新安装的软件内。

## 缓存与存储

你可以在这里查看应用占用的**存储空间**。

## 应用权限

你可以在此处查看**系统授予应用的对应权限**。点击可跳转到手机系统的权限配置页。

## 后台任务

你可以在**侧边栏任务页**：

- 设置后台任务
- 查看下载任务

你也可以**在对话中让 AI 创建任务**，固定定时任务会在时间到的时候由应用驱动唤醒 AI 开始执行。

::: warning 注意
后台任务需要**后台保活**才能执行。一般情况下，不建议无 root 用户使用，因为 root 用户有更好的系统级保活手段。
:::

## 文件管理器

在侧边栏**文件页**进入文件管理器：

- 需要授予软件**管理所有文件**的权限。
- 你可以在这里查看和修改文件。
- 进入代码文件进行编辑时，可以**拉取侧边 AI 对话页**直接对话辅助编辑和查看文件内容。

::: danger 提示
文件管理器为**半成品功能**，推荐使用 MT 管理器等更成熟的第三方文件管理器，而不是指望本应用。
:::

## 统计

在侧边栏**统计页面**进入，这里展示你使用本应用的：

- Token
- 对话
- 模型使用情况

支持日、周、月、年、总计以及历史日期和时间段查询。使用离线 Token 估算工具，不依赖网络服务。

> **如何清空统计？** 卸载重装！记得先备份数据。

## 日志

- 显示部分命令的执行情况。
- 通常情况下不需要查看，定时清理即可。
