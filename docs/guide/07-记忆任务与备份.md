# 第 7 章：记忆、定时任务与备份——让 AI 记住你、按时干活、数据无忧

> 这一章讲三件让 Lyra Code 更像"私人助理"的事：**① AI 的长期记忆；② 定时任务；③ 数据备份**。
>
> 预计阅读 20 分钟。

## 11. 记忆、子代理与项目指令

### 11.0 什么是「记忆」？——AI 的长期记事本

普通 AI 聊天是"每次失忆"的：关掉对话，它就不记得你是谁、你喜欢什么。

**记忆（Memory）** 就是给 AI 装一本**长期记事本**：

- 你告诉它「写文档用中文」「任务开始前先建 TODO」「推送插件前先更新 README」；
- 它把这些**明确、持久**的偏好记下来；
- **以后每次对话**，它都会自动翻出相关条目，按你的习惯办事。

### 11.1 记忆系统使用要点

- **存什么**：明确的偏好、工作方式、沟通习惯（如"回复用简体中文"）；
- **别存什么**：密钥密码、临时任务状态、一次性上下文（会泄露、会过时）；
- **按需注入**：AI 只使用与当前任务相关的记忆，**不会把整本记事本念给你听**；
- **随时可改**：你可以说「把记忆里"用中文回复"改成"用英文回复"」「删掉那条记忆」；
- **隐私**：记忆存在本机，跟着备份走。

::: tip 怎么让 AI 记住一件事？
直接说：「记住，以后所有代码注释都用中文写。」AI 就会把它存进记忆。
:::

### 11.2 子代理（Sub-Agent）：让 AI 分身并行干活

当任务里有**至少两个相互独立**的子任务时，AI 可以派「分身」（子代理）并行处理，比如：

- 同时调研两个技术方案；
- 同时审查两份代码；
- 设计两个备选方案再对比。

**原则：**

- 简单的回答、读已知文件、单次编辑、**前后依赖的步骤**，不适合派子代理；
- 子代理的结果**需要复核**，不能直接当最终结论；
- 子代理权限受限：不能执行命令、不能改共享存储、不能越权写文件。

> 新手不用主动管它——当任务确实适合并行时，AI 会自己决定是否派分身。

### 11.3 谁说了算？——指令优先级

```text
你的直接要求 > 当前对话 > 项目指令文件（AGENTS.md）> 记忆 > 示例
```

- 项目指令按目录树生效：**深层目录的规则覆盖浅层**；
- 任何指令（包括 AGENTS.md 和记忆）**都不能要求**：泄露密钥、绕过审批、执行无关的外部操作。

## 12. 定时任务与后台任务

### 12.0 这是什么？——让 AI 到点自动干活

定时任务 = **设定一个时间，到点让 AI 自动执行一件事**（在后台新开一个会话完成）。比如：

- 每天早上 8 点，让 AI 汇总昨天的待办；
- 每周五 18 点，让 AI 做一次数据备份；
- 每月 1 日，让 AI 导出备份到网盘。

### 12.1 四种计划类型

| 类型 | 触发参数 | 例子 |
| --- | --- | --- |
| 一次性（once） | 指定日期时间 | 明天 09:00 提醒我处理邮件 |
| 每天（daily） | 时 + 分 | 每天 22:00 生成当日写作进度总结 |
| 每周（weekly） | 星期几(1=周一…7=周日) + 时 + 分 | 每周五 18:00 备份 |
| 每月（monthly） | 几号 + 时 + 分 | 每月 1 日导出备份到 WebDAV |

### 12.2 怎么创建？——直接说人话

> 帮我创建一个定时任务：每周五晚上 6 点，把工作区里的小说进度总结写到 `总结.md` 里。

- 创建/修改/删除/启停都会要你确认；
- 定时任务可以指定自己的模型和资料，**不出现在普通聊天记录里**；
- **提示词要写清楚**：输出到哪个文件、什么格式——因为执行时是全新的独立会话，AI 不记得上下文。

### 12.3 后台命令（长驻服务）

需要一直运行的服务（本地开发服务器、长下载任务）用后台模式：

- App 会把启动输出保存到文件，并给你一个进程 ID；
- ⚠️ **启动成功 ≠ 服务健康**：要让 AI 另外检查进程状态和日志（`ps -ef | grep xxx` 或读输出文件）；
- 不要自己拼 `nohup ... &`——后台模式会自动处理。

### 12.4 超时与恢复

- 前台命令最长 600 秒；超时可能意味着命令还在跑或已悄悄完成；
- 先让 AI 用只读命令检查现场，再决定重试还是收尾；
- 定时任务期间**手机熄屏/被杀进程**可能影响触发——重要任务配合系统电源管理（把 App 加入电池白名单）。

### 12.5 新手 FAQ

**Q：定时任务没触发？**
A：检查：① 任务是否启用；② 时间/时区/星期设置；③ 手机有没有杀掉 App 后台；④ 任务提示词是否清楚（输出到哪）。

**Q：定时任务能联网吗？能调工具吗？**
A：能，它就是一次完整的 AI 会话，工具照常用。但要注意：你不在场时它执行，**审批怎么办**？——所以请只安排你信任的低风险任务。

## 13. 备份、迁移与导入导出

### 13.0 为什么要备份？

Lyra Code 里存着你的对话、模型配置、远程账号、记忆、Skills——**这些一旦丢了很难重建**。养成备份习惯，换手机、刷机、误删都不慌。

### 13.1 能备份什么？

| 分类 | 内容 |
| --- | --- |
| 个人资料 | 偏好设置、界面配置 |
| 对话历史 | 全部普通会话（定时任务会话不包含） |
| 模型配置 | 服务商、Base URL、预设模型 |
| 系统提示词 | 自定义 Prompt 库 |
| 远程配置 | MCP、SSH、邮件、WebDAV、FTP 账号 |
| Skills | 已导入的技能包 |
| 记忆 | 跨会话记忆条目 |

### 13.2 两种导出模式（务必分清）

| 模式 | 包含密钥吗 | 用途 | 注意 |
| --- | --- | --- | --- |
| **安全导出（默认）** | ❌ 不含 API Key/密码/私钥 | 常规备份、发给别人 | 恢复后需重新填密钥 |
| **完整迁移导出** | ✅ 包含全部密钥 | 换机、完整迁移 | ⚠️ **等同交出所有钥匙，必须加密保存，绝不公开分享** |

::: danger 重要警告
**完整迁移备份包含你的所有密码和密钥**，把它发到网盘/聊天工具里=把钥匙交给别人。用后立即删除副本。
:::

### 13.3 怎么导出/导入？

**导出**（说人话）：

> 帮我导出备份到本地（Download/LyraCode 文件夹），包含对话和设置，不含密钥。

- 也可以直接导出到 **WebDAV**（云备份）：指定网盘账号即可；
- WebDAV 未指定文件名时会覆盖 `/LyraCode/lyra_backup_latest.zip`。

**导入**（说人话）：

> 从工作区导入备份文件 `lyra_backup.zip`

- 导入支持：本地文件、下载目录、全局存储、WebDAV；
- **导入是补充模式**：非破坏、自动去重，尽量不覆盖你现有的密钥。

### 13.4 备份策略建议（抄作业）

1. 重要数据开启 **WebDAV 云备份**（自动、异地）；
2. 本地备份定期清理旧包，只留最近几个；
3. **换手机前**：先做一次「完整迁移导出」→ 新手机导入 → 用「安全导出」验证恢复路径；
4. 备份文件名带日期（如 `lyra-2026-08-14.zip`），避免覆盖旧版本。

### 13.5 新手 FAQ

**Q：备份文件被别人拿到会怎样？**
A：安全导出不含密钥，风险低；**完整迁移导出**等于交出所有钥匙——所以它绝不能外传。

**Q：导入会把现有数据覆盖吗？**
A：不会，导入是补充模式：新内容合并进来，已有的尽量保留。

**Q：多久备份一次？**
A：改动频繁就每周一次，纯聊天用户每月一次足够。有 WebDAV 的可以设成定时任务自动备份。
