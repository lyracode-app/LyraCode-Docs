## 16. 安全实践与权限控制

### 16.0 安全的第一原则

> **最小权限原则：给 AI 的权限，够用就好。**

AI 再聪明也是程序，权限越大、出事的后果越大。你不需要它动 Root，就别给 Root 权限。

### 16.1 权限最小化（怎么做）

- **用不到的工具就禁用**：在「Agent 工具页」关掉你不用的（比如不用 Root 就把 Root 工具关了）；
- **三档权限按需开**：Termux → Shizuku → Root，能不用高的就不用（见第 4 章）；
- **「所有文件访问」权限**：只在需要全盘管理文件时才授予，平时不给。

### 16.2 凭据与密钥（你的命根子）

- API Key、SSH 私钥、邮箱应用专用密码、MCP Token：**都只存本机**，备份默认不导出；
- **不要在对话里明文粘贴私钥**后要求转发给第三方；
- 含密钥的备份文件（完整迁移导出）**必须单独加密保管**。

### 16.3 网络与明文（小心 HTTP）

- HTTP 明文传输 = 数据可能被中间人看到。API / MCP / WebDAV / FTP / 微型服务器用 HTTP 时都要心里有数；
- 公网暴露、内网穿透、局域网共享**之前**：检查服务目录、认证、是否 HTTPS；
- **联网搜索黑名单**：把不信任的域名加进去；`*.x.com` 拦子域名，`x.com` + `*.x.com` 一起填才能全拦。

### 16.4 命令与远程操作（重点审查）

::: warning 高危操作审查
- 命令没有固定白名单，只拦截明显高危模式（`rm -rf /`、写系统设备、格式化磁盘等）——**审批弹窗出现时，务必人工看一眼**；
- 远程脚本、MCP 服务、Skills 仓库、SSH 命令：**信任判断由你自己负责**，来源不明的别用；
- 附件下载只进**隔离目录**，用杀毒软件扫描后再打开；
- 只预览可信的本地 HTML（网页里的脚本会以浏览器权限执行）。
:::

### 16.5 审批弹窗：每次点确认前问自己三个问题

1. **谁在调用什么工具？** 是 AI 在读写哪个路径、执行什么命令？
2. **这符合我让它做的事吗？** 有没有偷偷多做的动作？
3. **是敏感操作吗？** 发邮件、远程写入、删除——养成二次确认习惯。

> 发现可疑调用：**直接拒绝**，并告诉 AI 原因（"我不允许你访问这个文件"）。

### 16.6 新手安全清单

```text
□ 手机设置锁屏密码
□ API Key 只在服务商后台和 App 里出现
□ 不装来路不明的 Skill / MCP / 插件
□ 备份文件（含密钥的）加密保管、用完删除
□ 微型服务器只绑 127.0.0.1，除非确需局域网访问
□ 每个审批弹窗都看一眼再点
```

## 17. 常见问题与排查（排障手册）

### 17.1 命令执行不可用 / 被自动禁用

**可能原因**：Termux 没装、没开外部应用调用、设置里开关没开。

**解决**（按顺序检查）：
1. Termux 里确认 `allow-external-apps=true` 已写入，并执行过 `termux-reload-settings`（见第 1 章 5.3）；
2. Lyra Code 设置页的「Termux 权限」开关打开。

### 17.2 文件工具报「路径越界」

**原因**：你把绝对路径（如 `/storage/emulated/0/...`）传给了工作区工具。

**解决**：工作区外的文件改用 `global_*` 工具；或者先把文件移进工作区；不要传 Termux 私有路径。

### 17.3 edit_file 提示「匹配数不符」

**原因**：要替换的文本不唯一，或者文件已经被改过。

**解决**：重新读一遍文件，改用**行号区间**或**更长的唯一上下文**。别盲改重试。

### 17.4 命令输出被截断/看不全

**解决**：把输出存到文件再读：`命令 > out.txt 2>&1`；或缩小查询范围（`head` / `tail` / `rg` 精确匹配）。

### 17.5 微型服务器 404 / 页面异常

**解决**：让 AI 看 `read_mini_server_logs`：
- 404 → 路径不对或文件不存在；
- 认证失败 → 用户名密码不匹配；
- JS 报错 → 脚本有语法/路径问题；
- SPA 刷新 404 → 开 `spa_fallback`；
- 确认服务根目录里真的有你要的文件。

### 17.6 定时任务没触发

**解决**：检查任务启停状态、时间/时区/星期设置（1=周一）；手机电源管理/杀后台会影响触发，把 App 加入电池白名单；任务提示词里写清输出位置，方便事后核对。

### 17.7 邮件发送失败

**解决**：多数邮箱需要**应用专用密码**而非登录密码；检查 IMAP/SMTP 端口和加密（SSL/STARTTLS）；重复或不确定的投递不会被自动重试——先确认上次到底发了没有。

### 17.8 WebDAV / FTP 连不上

**解决**：先列目录测试可达性（`webdav_list` / `file_transfer_list`）；检查协议（https/davs/ftps/sftp）、端口、用户名、被动模式；改过密码后重新列账号拿新 id。

### 17.9 模型一直报错/转圈

**解决**：见第 2 章 4.5——检查 Key、模型名、网络、Base URL，四选一多半是它。

### 17.10 我忘了把权限开在哪

**快速索引**：

| 权限 | 位置 |
| --- | --- |
| 存储/通知 | 系统设置 → 应用 → Lyra Code → 权限 |
| 所有文件访问 | 系统设置 → 应用 → Lyra Code → 权限 → 所有文件访问权限 |
| Termux 命令通道 | Lyra Code 设置页 → Termux 权限 |
| Shizuku | Shizuku App 激活 + Lyra Code 设置页授权 |
| 工具开关 | Lyra Code → Agent 工具页 |

### 17.11 新手 FAQ

**Q：AI 会不会把我的聊天记录上传？**
A：不会。对话只发给你配置的模型服务商，不经过第三方中转；用量统计也是本地估算。

**Q：我把 API Key 发到网上了，怎么办？**
A：立刻去服务商后台**吊销并重新生成**，然后把新 Key 填进 App。

**Q：手机上没 Root，能用全部功能吗？**
A：能。Root 只是少数系统级操作才需要，日常功能完全不受影响。
