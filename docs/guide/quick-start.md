# 快速上手

本条目会指导你如何在 Lyra Code 配置好你的第一个 API 服务商，完成首次对话。

## 1. 打开侧边栏

安装打开应用后，你所看到的页面就是对话页面。此时你需要：

- 从**左向右滑动屏幕**，或者
- 点击对话页面**左上角**打开侧边栏

在侧边栏中找到带有**齿轮图标**的**设置**选项。

## 2. 进入模型服务

进入设置页面后，从**上往下数第二个**设置条目为**模型服务**，点击进入模型服务页面。

## 3. 选择模型服务商

在模型服务页面点击**右上角 `+` 号按钮**，进入选择模型服务商页面。你可以在此处选择你要使用的**预设模型服务商**。

## 4. 获取 API Key

使用预设模型服务商，你需要对应服务商的 API key。应用内置了跳转链接，你可以直接从应用内点击对应服务商的跳转链接直达对方官网或者控制台页面。之后依照对方网站的指引获取 API key，本条目不再赘述。

::: danger 安全提醒
对待 API Key 请像对待你的微信、支付宝支付密码一样，**请勿泄露**。你的 API Key 以及密码均会**加密后本地保存**，不会上传到 Lyra Code 的服务器。

（应用内置跳转链接是为了避免你直接搜索时误入带有银狐病毒的盗版网站。）
:::

## 5. 完成服务商配置

获取 API key 后：

1. 点击对应预设服务商进入**配置页**。
2. 粘贴好 API Key。
3. 点击下方**刷新模型列表**。
4. 选择好你想要使用的模型，**添加进启用模型**列表。
5. 点击**保存**。

至此服务商配置就完成了。

## 6. 切换服务商与模型

现在返回对话页，点击输入框**右下角 `+` 号按钮**，打开**底部动作面板**，可以在此处选择你的服务商和模型，并在后续对话中随时切换。

## 7. 发送第一句问候

发送一句“你好”吧！

## 可能出现的状况

### 1. 使用的服务商不在预设服务商里

你可以选择**自定义服务商**，这需要你自行前往对方网站获取 API key、接口格式、base URL 等配置，然后填写进配置中，后续步骤同上。

### 2. 无法获取模型列表 / 无法连接

- 部分服务商可能并不支持获取模型列表，你可以**手动填写**模型。
- 无法连接时，你需要核对 API key、base URL、路径是否填错，以及本地网络是否能连接到对方 API 服务器。

### 3. 对话选择模型时没有可选的模型

99% 是忘了把模型**添加进启用模型列表**里了，请重新查看上面的第 5 条。

### 4. 其他对话报错

因素比较复杂，建议复制报错内容喂其他 AI。对话失败会在页面显示具体的失败原因。
