# 第 3 章：界面总览——每个入口是做什么的

> 本章按当前 App 的实际导航介绍页面。第一次使用时先记住“侧边栏切功能、设置页配能力、对话页做任务”即可。

## 3.1 怎样打开侧边栏

在主界面点击左上角菜单图标，或者从屏幕左边缘向右滑。侧边栏分成三块：

1. 顶部个人资料；
2. 中部“功能”页面入口；
3. 下部历史会话和项目。

点击头像可以编辑昵称和头像。昵称主要用于本地显示，不是模型服务商账号。

## 3.2 功能入口速查

| 入口 | 能做什么 | 新手什么时候用 |
| --- | --- | --- |
| AI 对话 | 发消息、选模型、附加图片、调用工具 | 每次任务的主要入口 |
| 文件 | 双栏浏览、搜索、排序、复制、移动、编辑代码 | 查看和整理手机文件 |
| 终端 | 连接 SSH 或应用内 PRoot Linux | 需要交互式命令行时 |
| 日志 | 查看部分执行记录 | 排查运行问题时 |
| 统计 | 查看消息、Token 和模型使用估算 | 对比用量和成本时 |
| 任务 | 管理定时任务、查看下载进度和结果 | 自动化或大文件下载时 |
| 归档 | 管理已归档会话和项目 | 历史列表太长时 |
| 设置 | 配置模型、服务、权限、工具和外观 | 初次配置或修改功能时 |

## 3.3 AI 对话页

页面从上到下通常包括：

- **顶部栏**：菜单、新对话、当前标题，以及可展开的会话详情；
- **消息区**：用户消息、AI 正文、思考/过程记录、工具调用和文件变更；
- **输入区**：输入文字、停止/发送消息；
- **动作面板**：选择服务商、模型、系统提示词、Skill、工作区和其他会话选项。

展开会话详情可以核对当前服务商配置、模型、工作区和会话 ID。遇到“为什么用了错误模型/目录”的问题，先看这里。

消息和分支操作详见[对话操作](/guide/chat)。

## 3.4 历史会话和项目

侧边栏下方可以在 **会话** 与 **项目** 两种模式间切换：

- 搜索框会按标题、模型或状态过滤；
- 长按会话可以重命名、置顶、归档、删除或进入多选；
- 项目可以绑定一个工作区，并在项目下建立多个相关对话；
- 归档只隐藏，不等于删除。

多选适合一次整理多条普通会话。删除无法自动恢复，重要内容先备份。

## 3.5 双栏文件管理器

“文件”页由左右两栏组成，每栏都能独立进入不同目录。当前激活栏会有明显状态提示；复制或移动时，另一栏就是目标目录。

### 顶部菜单

- 进入 PRoot Linux instances；
- 授予或打开共享存储；
- 搜索当前路径及子目录；
- 按名称、修改时间、大小或类型排序；
- 切换升序和降序；
- 配置 Root / Shizuku 特权文件访问。

### 每栏底部按钮

- 返回上级目录；
- 刷新；
- 新建文件夹；
- 新建文件。

### 点击与长按

- 点击文件夹：进入目录；
- 点击普通文本/代码：用内置编辑器打开；
- 点击图片、视频等：进入预览或调用系统应用；
- 点击 APK：显示安装确认；
- 长按：进入操作菜单，可复制到另一栏、移动、重命名、看属性、解压、预览 HTML 或删除；
- 滑动选择：进入多选，可批量复制、移动或删除。

批量操作提交前会再次确认数量与方向。确认时同时核对“来源栏”和“目标栏”。

## 3.6 代码编辑器

内置 Sora Editor 支持行号、TextMate 语法高亮、文件内查找和替换、跳转到行、自动换行以及横向浏览。

### 保存规则

- 默认按 UTF-8 打开；
- 检测到解码错误时会警告；
- 继续编辑并保存会写成 UTF-8；
- 覆盖前会在同目录创建 `.bak`；
- 有未保存内容时退出会询问保存、取消或放弃。

### AI 助手侧栏

编辑器菜单里可以打开 **AI 助手**；界面也会提示从边缘滑出。专用会话会静默关联当前文件路径，你还可以添加项目工作区。AI 读取、编辑和保存当前文件时，编辑器会显示状态、审批、工具输出和变更回放。

不要在 AI 正在修改时同时手工大改同一段，否则可能产生版本冲突。先等待工具完成，再检查 diff 和最终文件。

## 3.7 终端页

终端页使用同一套界面连接两类目标：

- 已配置的 SSH 服务器；
- 已启用的 PRoot Linux 环境。

选择目标后点击连接。SSH 页面可以隐藏地址，避免截图泄露；遇到主机密钥变化时会拒绝连接，应先确认服务器是否重装或遭到中间人攻击。PRoot 的安装见[PRoot Linux](/guide/proot-linux)。

## 3.8 任务页

任务页包含：

- **定时任务**：新增、编辑、启停、删除，查看下次执行、最近结果和错误；
- **下载任务**：查看等待、速度、进度、成功或失败结果；
- **通知设置**：任务或下载完成/失败时发送系统通知；
- **清理已完成下载**：只清理任务记录，不等同于删除已经下载的文件。

详细用法见[定时任务与后台任务](/guide/scheduled-tasks)。

## 3.9 设置页三大分组

### 模型与服务

个人资料、模型服务、额外功能模型、子代理、联网搜索、Termux、PRoot Linux、MCP 客户端、MCP 服务端、SSH、邮件、WebDAV、FTP/FTPS/SFTP、微型服务器。

### 个性化

主题模式、自定义主题色、语言、字体和字体库、刷新率、聊天背景、流式输出、系统提示词、记忆、Skills。

### 通用

Agent 工具开关、缓存与存储、数据导出导入、Root/Shizuku 系统权限、媒体/位置/本地网络/摄像头/通知/应用列表/Termux 等应用权限、开源许可证和关于软件。

设置页顶部可以搜索。记不住入口时，输入“邮箱”“字体”“备份”等关键词即可。

## 3.10 新手安全习惯

1. 看清当前模型、工作区和目标路径；
2. 第一次使用高风险功能时保持默认审批；
3. 删除、覆盖、上传、发信和远程命令前逐项核对；
4. HTTP、FTP 等明文连接不要承载密码或私密文件；
5. 不用的 Root、Shizuku、MCP 服务端和局域网监听功能保持关闭；
6. 定期在“数据导出导入”中制作不含密钥的安全备份。
