# 第 15 章：MCP 接入——给 AI 插上 U 盘、接上传感器

> MCP（Model Context Protocol）是让 AI 连接外部工具/数据源的标准协议。你可以把它理解为**给 AI 插上 U 盘或接上传感器**。
>
> 预计阅读 10 分钟。

---

## 15.1 什么是 MCP？

MCP 是 AI 连接外部工具/数据源的**标准协议**。有了它，AI 不再只能用内置工具，还能调用第三方专业工具（比如数据库查询、天气查询）。

Lyra Code 同时支持两种角色：

- **MCP 客户端**：AI 去连接别人提供的 MCP 服务器，使用对方的工具；
- **MCP 服务端**：把 Lyra Code 自身的 Agent 工具暴露出来，提供给其他 MCP 客户端使用。

## 15.2 作为客户端（AI 去连别人的工具）

- 你可以在 **MCP 服务器页面**添加本地或者远程的 MCP 服务器：
  - 支持 **SSE 或 HTTP** 连接；
  - 支持连接远程 MCP 服务器（Streamable HTTP 或 SSE）；
- MCP 工具运行在**外部服务器**上，**不自动拥有你手机文件的权限**——每次调用都要你批准；
- 配置时需要服务器地址和必要的 Token/认证信息；
- 添加后你可以在 **AI Agent 工具页**查看新增的 MCP 工具，它们带有 **MCP 前缀**，非常好认。

## 15.3 作为服务端（把 Lyra Code 的能力开放给别人）

- 你可以在此处**启用 MCP 服务端**，将应用目前的 Agent 工具暴露出来，提供给本地和网络上其他 MCP 客户端使用；
- 支持自定义端口和可选认证 Key；
- ⚠️ **暴露到局域网 = 其他设备能访问**，必须设置认证 Key；暴露到公网风险更高，非必要别做。

> 如果你觉得本应用有原生工具很好用，但是又喜欢在其他 Agent 软件对话和工作，不妨使用本功能将工具提供给对方使用。

## 15.4 安全注意

- MCP 工具运行在外部服务器上，调用前请确认该工具的来源可信；
- MCP 工具**不自动拥有你手机文件的权限**——每次调用都要你批准；
- MCP 服务端暴露前务必设置认证 Key，非必要不要暴露到公网；
- 远程 MCP 服务的**信任判断由你自己负责**，来源不明的别用（更多安全实践见[第 22 章](/guide/security)）。
