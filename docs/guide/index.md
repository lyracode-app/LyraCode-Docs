# 简介

**Lyra Code** 是一款 Android 原生 AI Agent 应用，你可以在该应用中使用来自 OpenAI、Google Gemini、Anthropic Claude 以及其兼容 API 服务的 AI 服务商。

它在尽可能保持应用轻量的情况下，为 Android 端用户提供本地的 Coding 能力。全应用使用 Kotlin 编写，使用 Jetpack Compose 和 MD3 UI，贴近原生 Android 样式，内存占用小，响应迅速。

## 核心能力一览

- **多模型与多接口**：支持 OpenAI Chat Completions 兼容接口、Anthropic Messages API 和 Gemini GenerateContent API，可保存多个模型服务商、API Key、基础 URL、预设模型、自定义系统提示词和推理深度。
- **本地 Agent 能力**：工作区/全局文件操作、文件搜索、代码编辑、应用原生下载、命令执行、联网搜索、MCP 客户端/服务端、SSH、WebDAV、FTP/FTPS/SFTP、微型服务器、Skills、设备诊断和用量统计。
- **双栏文件管理器**：独立双栏浏览，适合跨目录复制移动文件；集成 Sora Editor 代码编辑器，支持语法高亮、行号、文件内搜索与 AI 对话侧栏。
- **多模态与内容渲染**：支持图片上传、拍照、裁剪、标注，支持 Markdown、表格、语法高亮代码块、LaTeX 数学公式渲染。
- **主题与个性化**：浅色/深色/跟随系统主题、Material You 动态配色（Android 12+）、字体字号、刷新率、聊天背景、技能与记忆管理。
- **数据与备份**：支持导入/导出个人资料、对话历史、模型配置、SSH、WebDAV 等配置，支持本地 zip 备份与 WebDAV 云备份。
