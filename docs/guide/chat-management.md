# 对话管理

本条目会指导你如何在 Lyra Code 中管理你的对话记录。

## 历史会话

打开侧边栏，你可以在此处看到**历史会话**。

- **点击对应会话**：进入该对话页，你可以继续对话。
- **长按对话记录**：打开对话记录菜单，你可以：
  - 修改对话标题
  - 置顶
  - 归档
  - 删除对话

## 归档对话和删除对话

- **归档**不会删除你的对话，它们会被收纳进**归档页面**。
- 你可以随时在归档页**恢复**或**彻底删除**对话。

::: tip 建议
善用归档来保持你的历史会话列表整洁。
:::

## 项目

**项目**功能是为多对话维护同一个工作目录而设置的。

它的整体使用逻辑和会话一致，但多了一个**目录层级**。
