# 第 5 章：对话管理——会话、项目、置顶与归档

## 5.1 会话和项目有什么区别

- **普通会话**：适合一次问答、临时任务或不需要固定目录的聊天；
- **项目**：绑定一个工作区，下面可以建立多个围绕同一批文件的会话，适合软件项目、论文、小说等长期工作。

例如维护一个网站时，可以创建“个人网站”项目并绑定网站目录，再分别新建“修复首页”“增加关于页”“部署排障”等对话。它们共享项目组织关系，但每个会话仍有自己的消息上下文。

## 5.2 查找历史会话

1. 打开左侧菜单。
2. 选择 **会话** 模式。
3. 在搜索框输入标题、模型名或状态关键词。
4. 点击结果继续对话。

未搜索时，会话按时间分组。置顶的会话会优先显示。

## 5.3 新建普通会话

点击界面中的新对话按钮。若当前已经是完全空白的新会话，应用会提示无需重复创建。第一条消息发送后，应用会保存会话，并可使用话题总结模型生成短标题。

新会话开始前建议核对：

1. 服务商和模型；
2. 系统提示词；
3. 是否需要工作区；
4. 是否强制使用某个 Skill；
5. 是否启用子代理。

## 5.4 长按会话可以做什么

| 操作 | 效果 | 能否恢复 |
| --- | --- | --- |
| 重命名 | 修改侧边栏显示标题，不改变消息 | 可以再次改名 |
| 置顶/取消置顶 | 调整列表位置 | 可以取消 |
| 归档 | 从普通列表移到归档页 | 可以恢复 |
| 多选 | 同时整理多条普通会话 | 取决于后续操作 |
| 删除 | 删除会话消息 | 不能自动恢复 |

删除前如需保留，请先到 **设置 → 数据导出导入** 导出包含对话历史的备份。

## 5.5 创建项目

1. 打开侧边栏并切换到 **项目**。
2. 点击搜索框右侧的新建项目按钮。
3. 输入项目名称，例如“毕业论文”。
4. 选择项目工作目录。
5. 创建后，在项目条目中新增会话。

项目名称用于组织，工作区才决定文件范围。选择目录时不要把整个共享存储根目录当作项目，最好每个项目一个独立文件夹。

## 5.6 管理项目

长按项目可以重命名、置顶、归档或删除。项目可以展开/折叠，其中列出归属它的会话。

::: warning 删除项目
删除项目会影响其组织下的会话。确认框出现时仔细阅读影响范围。它不会等同于删除手机上的工作区文件，但项目与聊天记录可能无法恢复。
:::

## 5.7 归档页

侧栏进入 **归档** 后，可以查看归档的会话与项目：

- **恢复**：移回普通列表；
- **彻底删除**：永久移除记录。

归档适合清理列表，不是备份。App 数据被清除或手机损坏时，归档内容一样会丢失。

## 5.8 整理建议

- 一次性问题使用普通会话；
- 同一目录的长期任务使用项目；
- 标题写“对象 + 任务”，例如“官网—修复移动端菜单”；
- 暂时不用但可能回看的会话归档；
- 确定无价值且备份过的再删除；
- 定期导出对话历史。

## 5.9 常见问题

### 为什么搜索不到消息正文

侧边栏搜索主要用于筛选会话标题、模型或状态，不等同于全文搜索。需要找旧内容时，可以让 Agent 使用会话历史搜索工具。

### 项目会自动把所有文件发给模型吗

不会。项目只绑定工作区；Agent 仍需按任务读取具体文件。不要因为绑定了目录就认为整个目录已经上传。

### 归档后文件会消失吗

不会。归档操作针对对话或项目记录，不会删除工作区里的真实文件。
