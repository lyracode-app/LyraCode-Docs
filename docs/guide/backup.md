# 第 20 章：备份与迁移——数据无忧

> Lyra Code 里存着你的对话、模型配置、远程账号、记忆、Skills——**这些一旦丢了很难重建**。养成备份习惯，换手机、刷机、误删都不慌。
>
> 预计阅读 15 分钟。

---

## 20.1 能备份什么？

| 分类 | 内容 |
| --- | --- |
| 个人资料 | 偏好设置、界面配置 |
| 对话历史 | 全部普通会话（定时任务会话不包含） |
| 模型配置 | 服务商、Base URL、预设模型 |
| 系统提示词 | 自定义 Prompt 库 |
| 远程配置 | MCP、SSH、邮件、WebDAV、FTP 账号 |
| Skills | 已导入的技能包 |
| 记忆 | 跨会话记忆条目 |

你可以在**数据导出导入页**导出指定数据文件，导出备份支持**自定义导出内容**。

## 20.2 两种导出模式（务必分清）

| 模式 | 包含密钥吗 | 用途 | 注意 |
| --- | --- | --- | --- |
| **安全导出（默认）** | ❌ 不含 API Key/密码/私钥 | 常规备份、发给别人 | 恢复后需重新填密钥 |
| **完整迁移导出** | ✅ 包含全部密钥 | 换机、完整迁移 | ⚠️ **等同交出所有钥匙，必须加密保存，绝不公开分享** |

::: danger 重要警告
**完整迁移备份包含你的所有密码和密钥**，把它发到网盘/聊天工具里=把钥匙交给别人。用后立即删除副本。
:::

## 20.3 怎么导出/导入？

**导出**（说人话）：

> 帮我导出备份到本地（Download/LyraCode 文件夹），包含对话和设置，不含密钥。

- 也可以直接导出到 **WebDAV**（云备份）：指定网盘账号即可；
- WebDAV 未指定文件名时会覆盖 `/LyraCode/lyra_backup_latest.zip`；
- 支持**本地 zip 备份**与 **WebDAV 云备份**两种方式。

**导入**（说人话）：

> 从工作区导入备份文件 `lyra_backup.zip`

- 导入支持：本地文件、下载目录、全局存储、WebDAV；
- 导入一共两种模式：
  - **补充导入**：在现有配置基础上新增。应用会识别备份包内是否有目前不存在的配置并新增，同配置会进行去重，适合任意情况下的备份导入；
  - **覆盖导入**：移除已有的所有配置，以备份包内的数据作为新配置，仅适合将数据迁移到新安装的软件内。

## 20.4 备份策略建议（抄作业）

1. 重要数据开启 **WebDAV 云备份**（自动、异地）；
2. 本地备份定期清理旧包，只留最近几个；
3. **换手机前**：先做一次「完整迁移导出」→ 新手机导入 → 用「安全导出」验证恢复路径；
4. 备份文件名带日期（如 `lyra-2026-08-14.zip`），避免覆盖旧版本。

## 20.5 新手 FAQ

**Q：备份文件被别人拿到会怎样？**
A：安全导出不含密钥，风险低；**完整迁移导出**等于交出所有钥匙——所以它绝不能外传。

**Q：导入会把现有数据覆盖吗？**
A：补充导入不会，它是非破坏模式：新内容合并进来，已有的尽量保留。覆盖导入才会清空重建，只用于迁移到新安装。

**Q：多久备份一次？**
A：改动频繁就每周一次，纯聊天用户每月一次足够。有 WebDAV 的可以设成定时任务自动备份（见[第 17 章](/guide/scheduled-tasks)）。
