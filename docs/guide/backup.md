# 第 20 章：备份与迁移——本地导出、云备份和换机恢复

## 20.1 备份入口

打开 **设置 → 数据导出导入**。页面分为：

1. 导出内容选择；
2. 是否包含密钥；
3. 本地导出；
4. 本地导入；
5. WebDAV 上传和云端补充导入。

## 20.2 可以选择哪些内容

- 个人资料与界面偏好；
- 对话历史；
- 模型服务配置；
- MCP 服务器配置；
- SSH 连接配置；
- 邮件服务器配置；
- 系统提示词；
- 个性化记忆；
- Skills；
- WebDAV 配置；
- FTP/FTPS/SFTP 文件传输配置。

不同版本的数据结构可能变化。跨版本导入会跳过不兼容结构，尽量导入可兼容部分。

PRoot Linux rootfs 可能达到数 GB，不在普通配置备份中；应用卸载或清除数据会删除它们。需要保留环境内文件时，先复制重要数据到共享存储。

## 20.3 不含密钥和包含密钥

| 模式 | 内容 | 使用场景 |
| --- | --- | --- |
| 不包含密钥 | 配置结构、名称、地址等，但不带 API Key、密码、私钥 | 日常备份、排障时共享、保存到普通云盘 |
| 包含密钥 | 可直接恢复登录的完整凭据 | 仅用于你自己控制的新手机迁移 |

::: danger 完整备份就是钥匙串
包含密钥的备份可能拥有模型额度、服务器、邮箱和网盘访问权。不要发给任何人，不要提交到 Git，不要放在无加密公共链接中。
:::

## 20.4 导出到手机

1. 勾选需要的分类。
2. 日常备份保持“包含密钥”关闭。
3. 点击 **导出到本地**。
4. 等待页面提示完成。
5. 文件会保存到 `Download/LyraCode`。
6. 打开文件管理器确认 zip 文件存在且大小不为 0。
7. 建议把文件名改成带日期的形式，例如 `lyra-safe-2026-08-23.zip`。

不要只看到“导出成功”就删除原数据；至少检查文件存在，并定期做一次恢复演练。

## 20.5 补充导入和覆盖导入

### 补充导入

在现有数据上合并，尽量去重，并降低已有密钥被覆盖的风险。适合：

- 日常恢复；
- 把旧手机部分数据合到新手机；
- 不确定备份内容是否完整；
- 从 WebDAV 云端恢复。

### 覆盖导入

移除现有对应数据，以备份内容重建。适合一台全新安装的设备做完整迁移。

::: warning 覆盖前先备份当前设备
覆盖导入会破坏现有配置。先导出当前状态，再核对备份文件来源、日期、大小和是否包含密钥。
:::

## 20.6 从本地文件导入

1. 把备份 zip 放在手机可访问位置。
2. 打开 **设置 → 数据导出导入**。
3. 新手先点 **补充导入**。
4. 在系统文件选择器中选择 zip。
5. 等待导入报告。
6. 查看每类导入数量和跳过项。
7. 逐项验证模型服务、对话、Skills 和远程配置。
8. 不含密钥的备份需要重新填写凭据并测试连接。

## 20.7 配置 WebDAV 云备份

先按[远程服务](/guide/remote#_14-7-webdav-添加网盘)添加并测试 WebDAV。

然后：

1. 回到 **数据导出导入**。
2. 选择 WebDAV 服务器。
3. 填写远程备份路径。
4. 选择导出内容和是否包含密钥。
5. 点击上传备份。
6. 等待上传成功提示，并在 WebDAV 客户端中确认远程文件存在。

未指定自定义名称时，应用可能使用固定的 latest 文件路径，后续上传会覆盖旧包。想保留历史版本，请为不同日期使用不同路径或在网盘端做版本管理。

## 20.8 从 WebDAV 导入

1. 选择保存备份的 WebDAV 服务器。
2. 填写远程备份路径。
3. 点击从云端导入。
4. 应用会下载并以补充模式导入。
5. 查看下载进度、使用的远程路径和导入结果。

云端导入默认采用更安全的补充模式。需要彻底换机时，可先把文件下载到本地，核对后再按覆盖流程操作。

## 20.9 换手机的稳妥流程

### 旧手机

1. 更新到计划使用的版本；
2. 先做一份不含密钥的安全备份；
3. 再做一份包含密钥的完整迁移备份；
4. 核对两个 zip 的日期和大小；
5. 通过你控制的加密方式传到新手机；
6. 旧手机暂时不要卸载或清数据。

### 新手机

1. 安装 Lyra Code；
2. 先导入完整迁移包；
3. 检查对话、模型、提示词、记忆、Skills 和远程配置；
4. 逐个做模型可达性、SSH、IMAP、WebDAV 等连接测试；
5. 确认无误后删除传输过程中的完整备份副本；
6. 最后再处理旧手机数据。

## 20.10 建议的备份策略

- 每周：不含密钥的本地或 WebDAV 备份；
- 重大配置修改前：额外导出一份；
- 换机前：安全备份 + 完整迁移备份各一份；
- 保留最近 3～5 个带日期版本；
- 定期在另一台测试设备或全新环境验证能否导入；
- 完整备份始终加密保管，使用后清理多余副本。

## 20.11 常见问题

### 导入后模型不能用

安全备份不含 API Key，需要重新填写。即使包含密钥，也应检查服务商 Key 是否被吊销或额度耗尽。

### 导入报告显示跳过

可能是重复项、版本结构不兼容或数据缺失。保留原备份，不要反复覆盖导入；先看具体分类和版本。

### 补充导入产生重复配置

应用会尽量去重，但名称相似、ID 不同的配置仍可能并存。逐项测试后再删除重复项。

### 能否备份下载文件和整个工作区

数据导出主要备份 App 配置与对话，不等同于手机文件备份。工作区、下载文件和 PRoot 环境应使用文件复制、Git、WebDAV 或其他专门方案。
