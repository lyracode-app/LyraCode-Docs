# 第 6 章：微型服务器与 Skills——在手机里开网站、给 AI 装技能

> 本章讲两个很酷的功能：**① 把手机变成一台"迷你网站服务器"**，预览你自己做的网页；**② 给 AI 安装"技能包"（Skills）**，让它学会特定本领。
>
> 预计阅读 20 分钟。

## 9. 内置微型服务器（Mini Server）

### 9.0 这是什么？——用大白话理解

微型服务器 = **在你手机里开一个小型网站服务器**。

- 它的"根目录"是**当前工作区**文件夹；
- 启动后，你（或局域网里的设备）可以通过浏览器访问手机上的网页；
- 最典型的用途：**预览你自己做的网站 / 文档站 / 前端项目**，改完立刻看效果。

### 9.1 使用流程：五步走

1. **让 AI 启动服务器**：对 AI 说「启动微型服务器，端口 8080」（它会调用内置工具，可能弹确认）；
2. **获取地址**：AI 会返回**本机地址**（如 `http://127.0.0.1:8080/`）和**局域网地址**（如 `http://192.168.x.x:8080/`）；
3. **打开预览**：在手机浏览器里打开地址，就能看到你的网站；
4. **出问题看日志**：让 AI「看看服务器日志」，排查 404、加载失败、JS 报错；
5. **用完关闭**：对 AI 说「关闭微型服务器」。

::: tip 新手示例
你刚用 AI 做了一个 `index.html` 放在工作区，就可以说：
「启动微型服务器，然后我预览一下 index.html」
:::

### 9.2 配置项一览（先不用背，看懂就行）

| 配置 | 作用 | 安全提醒 |
| --- | --- | --- |
| host | `127.0.0.1`=只有本机能访问；`0.0.0.0`=局域网都能访问 | 暴露后别人能访问你的网页 |
| port | 服务器端口（如 8080） | 端口冲突会启动失败 |
| username/password | 访问密码（Basic 认证） | **不设密码 = 谁都能打开** |
| protocol | HTTP 或 HTTPS | HTTP 是明文，别放敏感信息 |
| TLS 证书/私钥 | HTTPS 需要的证书 | 自签证书浏览器会警告 |
| force_https | 强制跳转 HTTPS | 需先配好证书 |
| spa_fallback | 单页应用（Vue/React）刷新 404 时回退首页 | 适合前端项目 |
| mdns | 局域网自动发现名称 | 方便同网设备找到 |

### 9.3 出问题怎么排查？

- **404（页面找不到）**：先看日志里的请求路径，确认文件存在、大小写一致；
- **认证失败**：检查用户名密码是否和设置一致；
- **JS 报错**：日志会记录页面脚本错误，先修脚本问题；
- **改动不生效**：浏览器缓存了旧页面，强制刷新（清除缓存/重新加载）；
- **SPA 刷新 404**：开启 `spa_fallback`；
- **预览 VitePress/Vite 项目**：先构建出静态文件（`build`），再启动服务器指向产物目录。

::: danger 安全红线
把服务器绑定到 `0.0.0.0`、内网穿透或公网之前，**务必检查**：服务目录里有没有敏感文件？设密码了吗？开 HTTPS 了吗？没有就绑 `127.0.0.1`。
:::

### 9.4 新手 FAQ

**Q：为什么局域网设备打不开？**
A：① 服务器绑定的是 `0.0.0.0` 吗（`127.0.0.1` 只允许本机）；② 两台设备在同一 WiFi 吗；③ 手机防火墙/路由器拦截了吗。

**Q：服务器启动失败/端口被占用？**
A：换一个端口（比如 8080 换成 9000）再启动。

**Q：能拿它做正式网站吗？**
A：它是本地预览工具，不是生产服务器。正式上线请用云服务器。

## 10. Skills 能力包

### 10.0 这是什么？——给 AI 装"技能书"

**Skill** 是一个"技能包"，包含一份说明书（`SKILL.md`）和配套文件。装上后，AI 在遇到相关任务时会**翻开这本说明书**，按里面的步骤干活。

打个比方：默认 AI 是个"什么都会一点的实习生"；Skill 就是**岗位培训手册**——装上"小说写作"技能包，它就知道怎么按你的大纲写小说。

### 10.1 怎么导入一个 Skill？（三种方式）

1. **zip 包**：别人发给你的技能包压缩文件（如 `小说SKILL.zip`），直接导入；
2. **单个 SKILL.md**：只有一份说明文档的，直接导入 Markdown 文件；
3. **Git 仓库链接**：从 GitHub / Gitee / GitLab 粘贴仓库地址导入。

> 也可以自己在应用里**手动编辑 SKILL.md**，从零创建一个技能。

### 10.2 SKILL.md 长什么样？（标准结构）

```markdown
---
name: my-skill              # 技能名字
description: 一句话说明这个技能做什么、何时被触发
---

# 使用说明

（Agent 读取后如何行动：步骤、规则、输出格式、注意事项）

## 参考文件

- prompts/template.md
- scripts/process.py
```

**两个关键点**：

- `name` 和 `description` 决定 AI **会不会**加载它——描述要写清楚"什么时候该用"；
- AI 会**先读 SKILL.md** 判断是否相关，**按需**再读内部文件，不会一股脑全加载（省 Token）。

### 10.3 怎么写出高质量 Skill？（进阶）

- 描述用「当用户要做 X 时」句式，减少误触发；
- 把稳定流程（步骤、格式、检查清单）写进 SKILL.md，AI 就不用每次重新摸索；
- 大脚本/模板放子文件，SKILL.md 只写"索引+怎么调用"；
- 标注环境假设（有些电脑上的工具在手机上可能没有，AI 会适配）；
- **不要把密钥写进 Skill 文件**（会随技能一起被读取）。

### 10.4 启用与管理

- 每个 Skill 可单独**启用/禁用**——禁用了 AI 就不会自动加载它；
- 通过配置管理可以列出、更新、删除 Skill；
- 打包时注意目录结构：**根目录放 SKILL.md**，子文件按相对路径引用。

### 10.5 新手 FAQ

**Q：Skill 是病毒吗？有风险吗？**
A：Skill 本质是文字说明+文件。但**别装来路不明的 Skill**——它可能教 AI 做一些危险操作。只装可信来源（官方/知名作者）的。

**Q：装了很多 Skill 会变慢吗？**
A：AI 按需读取，不会全加载。但描述写得模糊的 Skill 可能被误触发，描述写清楚就好。

**Q：Skill 能让我不用写提示词吗？**
A：能。把常用流程固化进 Skill 后，你说一句「开始」AI 就知道全套流程。
