# 第 18 章：Skills 技能包——给 AI 装"技能书"

> **Skill** 是一个"技能包"，包含一份说明书（`SKILL.md`）和配套文件。装上后，AI 在遇到相关任务时会**翻开这本说明书**，按里面的步骤干活。
>
> 预计阅读 15 分钟。

---

## 18.1 这是什么？——给 AI 装"技能书"

打个比方：默认 AI 是个"什么都会一点的实习生"；Skill 就是**岗位培训手册**——装上"小说写作"技能包，它就知道怎么按你的大纲写小说。

- 每个 Skill 有自己的 `name` 和 `description`，决定 AI **会不会**加载它；
- AI 会**先读 SKILL.md** 判断是否相关，**按需**再读内部文件，不会一股脑全加载（省 Token）。

## 18.2 怎么导入一个 Skill？（三种方式）

1. **zip 包**：别人发给你的技能包压缩文件（如 `小说SKILL.zip`），直接导入；
2. **单个 SKILL.md**：只有一份说明文档的，直接导入 Markdown 文件；
3. **Git 仓库链接**：从 GitHub / Gitee / GitLab 粘贴仓库地址导入。

> 也可以自己在应用里**手动编辑 SKILL.md**，从零创建一个技能。过大的技能包可能会被应用拒绝导入。

## 18.3 SKILL.md 长什么样？（标准结构）

```markdown
---
name: my-skill              # 技能名字
description: 一句话说明这个技能做什么、何时被触发
---

# 使用说明

（Agent 读取后如何行动：步骤、规则、输出格式、注意事项）

## 参考文件

- prompts/template.md
- scripts/process.py
```

**两个关键点**：

- `name` 和 `description` 决定 AI **会不会**加载它——描述要写清楚"什么时候该用"；
- AI 会**先读 SKILL.md** 判断是否相关，**按需**再读内部文件，不会一股脑全加载（省 Token）。

## 18.4 怎么写出高质量 Skill？（进阶）

- 描述用「当用户要做 X 时」句式，减少误触发；
- 把稳定流程（步骤、格式、检查清单）写进 SKILL.md，AI 就不用每次重新摸索；
- 大脚本/模板放子文件，SKILL.md 只写"索引+怎么调用"；
- 标注环境假设（有些电脑上的工具在手机上可能没有，AI 会适配）；
- **不要把密钥写进 Skill 文件**（会随技能一起被读取）。

## 18.5 启用与管理

- 每个 Skill 可单独**启用/禁用**——禁用了 AI 就不会自动加载它；
- 通过配置管理可以列出、更新、删除 Skill；
- 打包时注意目录结构：**根目录放 SKILL.md**，子文件按相对路径引用；
- 在对话输入框开头输入 `/` 也可以引导 AI 读取指定技能。

## 18.6 新手 FAQ

**Q：Skill 是病毒吗？有风险吗？**
A：Skill 本质是文字说明+文件。但**别装来路不明的 Skill**——它可能教 AI 做一些危险操作。只装可信来源（官方/知名作者）的。

**Q：装了很多 Skill 会变慢吗？**
A：AI 按需读取，不会全加载。但描述写得模糊的 Skill 可能被误触发，描述写清楚就好。

**Q：Skill 能让我不用写提示词吗？**
A：能。把常用流程固化进 Skill 后，你说一句「开始」AI 就知道全套流程。
