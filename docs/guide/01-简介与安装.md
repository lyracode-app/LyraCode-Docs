# 第 1 章：Lyra Code 是什么？怎么安装？（新手必读）

> 这一章是写给**第一次接触 Lyra Code** 的你。如果你连「APK」「API Key」「终端」这些词都没听过，完全没关系——我们会从零开始，一个词一个词地解释，每一步都告诉你屏幕上会看到什么、点哪里、出错了怎么办。
>
> 读这一章预计需要 15 分钟。读完后，你就能成功安装并完成基础配置。

---

## 0. 开始之前：先花 5 分钟搞懂几个词

下面这些词在整份文档里会反复出现。先花几分钟混个脸熟，后面就不会懵了。

### 0.1 什么是「AI 模型」？

AI 模型（也叫大语言模型、LLM）可以理解为**一个装在云端服务器里的「超级大脑」**。

- 它平时不装在你手机里，而是在别人的服务器上运行；
- 你的手机把问题发给它，它把答案发回来；
- 常见的模型有：OpenAI 的 GPT 系列、Anthropic 的 Claude 系列、Google 的 Gemini 系列，以及国内的 DeepSeek、Moonshot（Kimi）等。

**关键点**：Lyra Code 本身**不带模型**。你需要自己选择一家模型服务商，把手机和它的服务器连起来，才能开始对话。怎么连，见第 2 章。

### 0.2 什么是「API Key」？

API Key 是**模型服务商发给你的一串「通行证密码」**，类似：

```
sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

- 它的作用是证明「这台手机是我（付费用户）在用」；
- 你去模型服务商的官网注册账号、充值后，就能在网站上生成自己的 API Key；
- **API Key 相当于钱和身份凭证，千万不能发到网上、不能截图发群里**。泄露了别人就能用你的额度。

### 0.3 什么是「Agent（代理）」？

Agent 翻译成「代理」，意思是：**AI 不只是回答你，还能代替你动手做事**。

普通聊天软件：你问 → 它答。

Agent（Lyra Code）：你说「帮我把下载好的压缩包解压，把里面的图片整理到相册文件夹」→ 它会自己规划步骤、读取文件、执行操作，每一步先征求你的同意。

### 0.4 什么是「命令 / 终端 / Shell」？

- **命令**：一行行的文字指令，比如 `ls`（列出文件）、`git push`（上传代码）；
- **终端（Terminal）**：输入命令的窗口；
- **Shell**：负责执行命令的「翻译官」程序；
- **Termux**：Android 手机上的一款终端 App，相当于在手机上开了一个「命令行窗口」。

在 Lyra Code 里，AI 可以通过 Termux 帮你执行命令（装软件、跑脚本、管理文件等）。这是它的核心能力之一，后面第 5 节会教你怎么配置。

### 0.5 什么是「工作区（Workspace）」？

工作区是**一个专门的文件夹**，Lyra Code 的 AI 默认只在这个文件夹里读写文件，防止它乱动你手机上的其他东西。

- 默认工作区：`/storage/emulated/0/Lyra`（也就是手机存储根目录下的 `Lyra` 文件夹）；
- 你可以把项目文件夹、写作草稿等都放在这里。

### 0.6 Termux、Shizuku、Root 分别是什么？

| 名字 | 是什么 | 权限级别 | 什么时候需要 |
| --- | --- | --- | --- |
| Termux | 手机上的终端 App | 普通应用权限 | 执行命令、跑脚本、装软件（**几乎人人都需要**） |
| Shizuku | 一个「借用系统调试权限」的服务 | 较高（ADB 级别） | 查询系统信息、批量管理应用等高级操作 |
| Root | 手机被「越狱式」破解后的超级权限 | 最高 | 修改系统文件等极少数场景 |

::: tip 新手提醒
你只需要先搞定 **Termux**。Shizuku 和 Root 用不到就先不管，等以后需要了再回来学。
:::

## 1. Lyra Code 到底是什么？

用一句话说：

> **Lyra Code 是安装在 Android 手机上的一款「本地 AI 助手 + 文件管理器 + 代码编辑器 + 万能工具箱」应用。**

它的特殊之处在于三个词：

### 1.1 本地优先（你的数据在你手里）

- 你的模型 Key、对话记录、文件、账号密码，**都保存在手机本地**；
- 不会像某些 App 那样把你的对话上传到它们的服务器再「中转」；
- 你的隐私只在你和模型服务商之间发生。

### 1.2 Agent 化（AI 能动手干活，但每次都要你点头）

- AI 可以读你的文件、改你的代码、执行命令、连接远程服务器；
- 但**每一个有风险的动作，都会弹出确认框等你批准**；
- 你不点头，它什么都改不了。这就是「可控」。

### 1.3 可扩展（像乐高一样拼功能）

- **Skills**：下载别人的「技能包」，AI 就能学会特定技能（比如写小说、做数据分析）；
- **MCP**：连接外部工具和数据的标准接口；
- **定时任务**：让 AI 每天早上自动帮你做一件事。

## 2. 我适合用吗？

### ✅ 适合你，如果……

- 你想在手机上写代码、改文件、跑脚本；
- 你经常处理邮件、网盘、FTP 服务器，想让 AI 帮你跑腿；
- 你是作者/创作者，想让 AI 帮你写作、整理资料、管理进度；
- 你想体验「AI 自主干活但完全受控」的感觉。

### ❌ 不太适合，如果……

- 你只是想找个聊天机器人闲聊（那用普通 AI 聊天 App 更简单）；
- 你的手机是 Android 8.0 以下的老机型（运行不了）；
- 你完全不想学任何新东西、连「同意权限弹窗」都嫌麻烦。

## 3. 它能帮我做什么？（能力速览）

| 能力 | 通俗解释 | 举个具体例子 |
| --- | --- | --- |
| 模型接入 | 接入多家 AI 服务商 | 用 Kimi 聊天、用 Claude 写代码，随时切换 |
| Agent 工具 | AI 读写文件、执行命令、联网搜索 | 「帮我看看这个项目里有哪些 TODO」 |

| 定时任务 | 让 AI 按计划自动工作 | 每天 22:00 生成写作进度总结 |
| 备份 | 一键备份/恢复所有数据 | 换手机前导出完整备份 |

## 4. 开始安装（一步一步来）

### 4.1 第一步：确认手机满足条件

**最低要求：Android 8.0（API 26）及以上。**

怎么查你的 Android 版本：

```text
打开「设置」→ 找到「关于手机」→ 查看「Android 版本」一栏
```

- 如果是 **Android 8.0 及以上**（绝大多数手机都满足）→ 继续；
- 如果更低 → 抱歉，这台手机运行不了，需要换设备。

### 4.2 第二步：下载安装包（APK）

**什么是 APK？** APK 就是安卓软件的安装包文件，就像电脑上的 `.exe`。

Lyra Code 有两个官方下载渠道（任选其一）：

1. **GitHub Releases**：访问 `https://github.com/lyracode-app/Lyra-Code/releases`，找到最新版本，下载 `.apk` 文件；
2. **Gitee**：国内访问 GitHub 慢的话，去 Gitee 的 Lyra Code 仓库 Releases 页下载。

::: warning 安装时提示「未知来源」怎么办？
Android 出于安全考虑，默认禁止安装非应用商店的 App。当你点击 APK 时会弹窗提示，点 **「仍要安装 / 允许此来源」** 即可。这是正常的，因为 Lyra Code 本来就是从官网下载的。
:::

### 4.3 第三步：首次打开会看到什么

安装完成后，桌面上会出现 Lyra Code 图标，点开它。

第一次启动时，手机会弹出**权限请求**，一般有两个：

| 权限 | 弹窗会怎么说 | 该不该给 | 不给会怎样 |
| --- | --- | --- | --- |
| 存储权限 | 「允许 Lyra Code 访问照片和文件？」 | ✅ 允许 | 无法读取/保存文件，核心功能不可用 |
| 通知权限 | 「允许 Lyra Code 发送通知？」 | ✅ 允许（推荐） | 定时任务完成时无法提醒你 |

> 如果手滑点了「拒绝」，别慌：随时可以去 `设置 → 应用 → Lyra Code → 权限` 里补开。

### 4.4 第四步：给文件管理器开「所有文件访问」权限（Android 11 及以上）

Lyra Code 自带一个双栏文件管理器，默认浏览 `/storage/emulated/0`（手机存储根目录）。**Android 11 及以上**需要单独授予「管理所有文件」权限：

```text
设置 → 应用 → Lyra Code → 权限 → 所有文件访问权限 → 允许
```

::: tip 各品牌手机路径可能略有不同
小米/红米：设置 → 应用设置 → 应用管理 → Lyra Code → 权限管理 → 所有文件访问权限
华为/荣耀：设置 → 应用 → 应用管理 → Lyra Code → 权限 → 所有文件访问权限
OPPO/vivo：设置 → 应用管理 → Lyra Code → 权限 → 存储和文件 → 所有文件访问权限
三星：设置 → 应用 → Lyra Code → 权限 → 文件和媒体 → 允许管理所有文件
:::

**不开会怎样？** 文件浏览、复制、删除等批量操作会受限。如果只用 AI 对话不碰文件，可以先不开，等需要时再补。

## 5. 配置 Termux（让 AI 能执行命令）

这是新手最容易卡住的一步，我们慢慢来。

### 5.1 为什么必须装 Termux？

Lyra Code 的「执行命令」能力，是通过另一个叫 **Termux** 的 App 来实现的。**没装 Termux，AI 就不能运行任何命令**（不能装软件、不能跑脚本、不能管理 Git）。

### 5.2 安装 Termux

- 在 **F-Droid**（Termux 官方推荐的商店）搜索 Termux 安装，或者去官网 `https://termux.dev` 下载；
- 安装后打开一次 Termux，让它完成首次初始化（会显示一个命令行窗口，这是正常的）。

### 5.3 打开「允许外部应用调用」开关

在 Termux 里输入下面这行命令（可以直接复制粘贴），然后按回车：

```bash
mkdir -p ~/.termux && (grep -qxF 'allow-external-apps=true' ~/.termux/termux.properties || echo 'allow-external-apps=true' >> ~/.termux/termux.properties) && termux-reload-settings
```

**这行命令干了三件事**（不理解没关系，执行就好）：
1. 创建 Termux 的配置目录；
2. 在配置文件里写入 `allow-external-apps=true`（允许其他 App 调用 Termux）；
3. 重新加载设置让配置生效。

### 5.4 安装基础软件包（建议执行）

在 Termux 里输入下面这行，按回车（第一次会下载几百 MB 数据，耐心等待）：

```bash
pkg update && pkg install git openssh python nodejs-lts ripgrep file
```

| 软件包 | 有什么用 |
| --- | --- |
| git | 代码版本管理（从 GitHub 下载/推送项目） |
| openssh | SSH 远程连接服务器 |
| python | 运行 Python 脚本 |
| nodejs-lts | 运行 JavaScript/Node.js 项目 |
| ripgrep | 快速搜索文件内容 |
| file | 查看文件类型 |

> 如果提示 `pkg: command not found`，说明 Termux 没初始化好，先关掉 Termux 重新打开一次，或更新一下：`pkg update`。

### 5.5 回到 Lyra Code，打开 Termux 权限开关

1. 打开 Lyra Code → 右下角/侧边栏进入**设置页**；
2. 找到 **「Termux 权限」** 或类似开关；
3. 把它**打开**（会弹出授权提示，点允许）。

::: danger 常见错误
**没开这个开关的话，AI 的 `run_command` 工具会自动禁用**——你让 AI 跑命令，它会说「命令执行不可用」。这时候回来检查这一节的三步：Termux 装了没？`allow-external-apps=true` 写了没？设置里的开关开了没？
:::

### 5.6 验证配置是否成功

配置完成后，回到对话页，对 AI 说：

> 帮我执行命令 `echo hello` 看看能不能用

如果正常，AI 会执行并返回 `hello`。恭喜，命令通道打通了！

## 6. 设置页逐项说明（新手版）

进入设置页后，你会看到这些配置项。**大多数保持默认就好**，但你要知道它们是干嘛的：

| 配置项 | 它是干嘛的 | 新手建议 |
| --- | --- | --- |
| 模型服务商 | 添加/管理你的 AI 服务商、API Key、模型 | **必配**（第 2 章详解） |
| 系统提示词 | 设定 AI 的「人设」和行事规则 | 暂不动 |
| Termux 权限 | 命令执行通道的开关 | **必开**（见 5.5） |
| 联网搜索黑名单 | 屏蔽不想让 AI 打开的网站 | 暂不动 |
| Agent 工具开关 | 逐个启用/禁用 AI 的工具 | 暂不动 |
| 主题/字体/刷新率 | 界面显示效果 | 按喜好调 |
| 备份 | 导出/导入你的数据 | 建议装好后先备份一次 |

## 7. 新手最容易踩的 6 个坑

1. **没装 Termux 就让 AI 跑命令** → 提示「命令不可用」。按第 5 节配置。
2. **没给存储权限** → 文件相关操作报错。去系统设置里补开权限。
3. **API Key 填错/没填** → AI 一直报错或转圈。检查服务商配置（见第 2 章）。
4. **手机存储路径找不到** → 记住默认工作区是 `/storage/emulated/0/Lyra`，不是 `/storage/emulated/0` 本身。
5. **把 API Key 发到群里/网上** → 立刻去服务商后台吊销并重新生成。
6. **遇到弹窗直接点「拒绝」** → 很多权限后面很难想起在哪补，先点允许，不需要的以后也能关。

## 8. 常见问题 FAQ

**Q：Lyra Code 收费吗？**
A：应用本身免费开源。你付钱的对象是**模型服务商**（按使用量计费，通常很便宜）。

**Q：一定要有 API Key 才能用吗？**
A：是的。模型跑在服务商服务器上，必须有 Key 才能调用。免费额度很少或没有，建议充少量钱（一般几块钱够用很久）。

**Q：不装 Termux 行不行？**
A：可以，但 AI 会失去执行命令的能力，很多高级功能用不了。建议装。

**Q：换了新手机怎么把数据搬过去？**
A：用备份功能：旧手机导出备份 → 新手机导入（详见第 13 节）。

**Q：手机很卡，是 Lyra Code 的问题吗？**
A：AI 推理在云端，手机本地不跑大模型，一般不会卡。卡顿可能是网络或后台任务。
