# 第 8 章：模型与多服务商——把 AI 服务商接进来

> 本章完成**最关键的一步：把 AI 服务商接进来**。配置好之后，你就能真正开始和 AI 对话了。
>
> 预计阅读 15 分钟。

---

## 8.1 先搞懂三个词

- **服务商（Provider）**：提供 AI 模型的公司/平台，比如 OpenAI、DeepSeek、Moonshot（Kimi）、Google；
- **模型（Model）**：服务商旗下具体的大脑版本，比如 `gpt-4o`、`deepseek-chat`、`kimi-k2`；
- **Base URL**：服务商的服务器地址，一般是一串网址。**用官方服务商通常不用填**（App 内置了默认地址），只有用第三方网关或自己搭建的服务器才需要填。

## 8.2 Lyra Code 支持哪几类服务商？

| 协议 | 怎么理解 | 常见服务商 |
| --- | --- | --- |
| OpenAI 兼容接口 | 行业通用标准，绝大多数服务商都支持 | OpenAI、DeepSeek、Moonshot、本地 Ollama/vLLM 等 |
| Anthropic Messages API | Claude 专用接口 | Anthropic（Claude 系列） |
| Gemini GenerateContent API | Google 专用接口 | Google（Gemini 系列） |

**新手建议**：优先选一家「OpenAI 兼容」的国内服务商（如 DeepSeek、Moonshot），便宜、稳定、网络友好。

## 8.3 添加服务商：一步步来

1. 打开 **设置页** → 找到 **「模型服务商」**（或类似入口）；
2. 点 **「添加 / 新增」**；
3. 按表格填写（见 8.4）；
4. 保存后，回到对话页，**在底部动作面板里选中刚添加的服务商和模型**；
5. 发一句「你好」测试。

**能成功收到回复，就说明配置完成。** 如果报错，看下面的 8.6。

::: tip 预设服务商与自定义服务商
- **预设模型服务商**：应用内置了常用服务商的跳转链接，你可以直接从应用内点击对应服务商的跳转链接直达对方官网或者控制台页面，依照对方网站的指引获取 API key。
- **自定义服务商**：你使用的服务商不在预设列表里时，需要自行前往对方网站获取 API key、接口格式、base URL 等配置，再填写进配置中。

（应用内置跳转链接是为了避免你直接搜索时误入带有银狐病毒的盗版网站。）
:::

::: danger 安全提醒
对待 API Key 请像对待你的微信、支付宝支付密码一样，**请勿泄露**。你的 API Key 以及密码均会**加密后本地保存**，不会上传到 Lyra Code 的服务器。
:::

## 8.4 每个配置项是什么意思？

| 配置项 | 填什么 | 举个例子 | 新手提示 |
| --- | --- | --- | --- |
| 服务商名称 | 随便起个方便认的名字 | `我的DeepSeek` | 多个服务商时靠它区分 |
| API Key | 服务商后台生成的密钥 | `sk-xxxx...` | **只存本机；别泄露** |
| Base URL | 服务商服务器地址 | `https://api.deepseek.com` | 官方服务商一般不填 |
| 预设模型 | 你想用的模型名 | `deepseek-chat` | 填服务商文档里的准确名称；不支持获取模型列表时可**手动填写**，添加进**启用模型**列表 |
| 自定义系统提示词 | 设定 AI 的人设/规则 | 「你是一位严谨的中文编辑」 | 可以存多套，随时切换 |
| 推理深度 | 推理类模型（如 o 系/R 系）的思考强度 | 低/中/高 | 非推理模型无需设置 |

## 8.5 多服务商切换技巧

- 对话页底部的**动作面板**支持一键切换：**服务商 / 模型 / 提示词**；
- **比效果**：同一个问题，先切到 A 模型问一次，再切到 B 模型问一次，对比哪个回答好；
- **分场景**：编码用一个提示词（"你是资深 Kotlin 工程师"），写作用另一个（"你是小说作者"），切换提示词就能改变 AI 的行为风格；
- **私有化部署**：如果你自己电脑上跑着 Ollama / vLLM / LM Studio，它们也走 OpenAI 兼容协议——Base URL 填你的局域网地址（如 `http://192.168.1.5:11434/v1`）即可，完全免费、数据不出门。

## 8.6 新手常见问题 FAQ

**Q：添加后一直报错/转圈？**
A：按顺序检查：① API Key 复制全了吗（别带空格）；② 服务商名称和模型名写对了吗；③ 网络能访问该服务商吗；④ Base URL 填对了吗（官方服务商留空）。

**Q：无法获取模型列表 / 无法连接？**
A：部分服务商可能并不支持获取模型列表，你可以**手动填写**模型。无法连接时，核对 API key、base URL、路径是否填错，以及本地网络是否能连接到对方 API 服务器。

**Q：对话选择模型时没有可选的模型？**
A：99% 是忘了把模型**添加进启用模型列表**里了，请重新查看上面的 8.4。

**Q：提示 401 / 认证失败？**
A：API Key 无效或已过期。去服务商后台重新生成一个，替换掉。

**Q：提示额度不足 / insufficient balance？**
A：账户没钱了。去服务商官网充值（一般几块钱能用很久）。

**Q：哪个服务商便宜？**
A：价格变化快，建议用「OpenAI 兼容」的国内平台对比，或者看[第 21 章「用量统计与设备诊断」](/guide/stats)自己测。

**Q：可以同时添加多家吗？**
A：可以，随便加，数量不限。切换只在对话页底部点一下。

**Q：其他对话报错？**
A：因素比较复杂，建议复制报错内容喂其他 AI。对话失败会在页面显示具体的失败原因。
