# 第 7 章：个性化与主题——把界面调到舒服好用

所有入口都在 **设置 → 个性化** 分组。设置页可以搜索关键词，不必记住位置。

## 7.1 个人资料

点击 **个人资料** 可修改昵称和头像。它们用于 App 内显示，不会改变模型服务商账号，也不会作为 API Key 使用。

## 7.2 主题模式

进入 **主题设置 → 主题模式**：

- **跟随系统**：手机切换明暗模式时自动同步，最适合新手；
- **浅色**：始终使用亮色；
- **深色**：始终使用暗色。

Material You 动态配色需要 Android 12 或更高版本，并受系统壁纸颜色影响。

## 7.3 自定义主题色

1. 打开 **主题设置 → 自定义主题色**。
2. 启用开关。
3. 在色环选择颜色，或输入六位十六进制色值，例如 `#5B7CFA`。
4. 先看预览，再点击保存。
5. 在确认框中再次确认后才会应用。

自定义主题色会协调背景、卡片、输入框和侧边栏等表面颜色。它会接管明暗对比判断；关闭后才可恢复普通主题模式选择。返回而不保存不会修改当前配色。

## 7.4 语言

支持优先使用设备语言，也可手动选择简体中文、繁体中文或 English。若系统语言没有对应翻译，会回退到英语。

修改后若个别页面没有立即刷新，可返回上一级或重启 App。

## 7.5 字体大小

进入 **主题设置 → 字体与大小**，拖动滑块并观察预览。新手从标准大小开始，长时间阅读时以不费眼为准，不要只追求一屏显示更多内容。

## 7.6 字体库

字体库支持批量导入 TTF、OTF 和 TTC 文件，并分别设置：

- **文本字体**：菜单、正文和对话文字；
- **代码字体**：代码块和编辑器内容。

操作步骤：

1. 打开 **字体与大小 → 字体库**。
2. 点击 **导入字体**，可一次选择多个文件。
3. 点击字体查看常规、粗体、斜体、中文、英文和数字预览。
4. 选择 **设为文本字体** 或 **设为代码字体**。
5. 不再使用时可从字体库移除；系统默认字体随时可以恢复。

只导入来源可信的字体文件。字体设计不完整时，部分字符会回退到系统字体。

## 7.7 刷新率

可选跟随系统智能刷新率，或请求 30、60、90、120 Hz。固定值只是向 Android 提出偏好，最终取决于屏幕硬件、系统策略、省电模式和温度。

新手保持 **跟随系统智能刷新率**。高刷新率更流畅，但可能增加耗电。

## 7.8 聊天背景

进入 **主题设置 → 聊天背景** 上传图片。选择内容简洁、对比度合适的图片，避免让文字难以阅读。若页面看不清，先恢复默认背景再调整主题色。

## 7.9 流式输出动画

- **逐字显示**：经典打字机效果；
- **渐变显示**：新内容从透明平滑变清晰。

这只改变显示动画，不改变模型生成速度、回答内容或计费。

## 7.10 系统提示词

系统提示词是发给模型的长期角色与规则。应用原生提示词已针对 Lyra Code 工具和 Android 环境适配，新手建议保持默认。

需要写作、翻译或固定输出格式时，可以新增一套自定义提示词，然后在对话动作面板中切换。写法建议：

```text
你是一名耐心的中文技术编辑。
先解释术语，再给编号步骤。
不确定的内容必须明确说明，不要猜测。
```

不要在系统提示词里保存 API Key、密码或个人隐私。提示词也不能绕过应用的安全限制和审批规则。

## 7.11 常见问题

### 主题色保存后太亮或太暗

回到自定义主题色选择更适中的颜色，或关闭自定义主题色并恢复跟随系统。

### 导入字体后代码对不齐

把代码字体恢复为系统默认或选择等宽字体。普通装饰字体不适合代码编辑。

### 高刷新率没有生效

设备可能不支持该刷新率，或者省电模式/系统策略覆盖了请求。这不属于模型或网络故障。
