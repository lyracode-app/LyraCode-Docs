# 个性化

本条目会指导你如何在 Lyra Code 中调整界面和部分个性化功能。

## 个人资料

- 设置你的**昵称和头像**。
- 此功能是旧版本搭配**沉浸扮演模式**使用的。在新版本中，此功能并无设置意义，但为了个性化区分，并未移除。

## 主题

你可以在**主题页**中设置：

- 配色
- 预测性返回手势
- 字体字号
- 语言
- 刷新率
- 流式对话动画
- 聊天背景

::: warning 动态配色
动态配色（Material You）仅支持 **Android 12 及以上**设备，低于此版本修改不生效。
:::

## 系统提示词

- 本软件内置**默认提示词**，通常情况下不需要你额外修改。
- 如果你需要**角色扮演**、或非编程等其他需求，可以**新增**你的提示词。
- 系统提示词决定了 AI 的**自我认知**，期望向 AI 询问"你是什么模型"来获取正确模型名是不实际的。
- 你可以通过查看源码、逆向应用或者直接向 AI 询问获取本应用的原生提示词。

## 技能（Skills）

- 你可以通过**仓库链接**（GitHub / Gitee / GitLab）或者**本地文件**导入技能。
- 过大的技能包可能会被应用拒绝导入。
- 你也可以手动编辑 `SKILL.md` 创建 Skill。
- Agent 会先读取 `name` / `description` 判断是否相关，再按需读取 Skill 内部文件，避免上下文爆炸。

## 记忆

- 在对话中，AI 可能会将你的习惯**保存进记忆**里。
- 你可以在 **设置 → 记忆** 中查看和管理 AI 保存的记忆。
