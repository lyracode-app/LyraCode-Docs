# 第 7 章：个性化与主题——按你的喜好打扮应用

> 这一章指导你如何调整 Lyra Code 的界面显示与个性化功能。
>
> 预计阅读 8 分钟。

---

## 7.1 个人资料

- 设置你的**昵称和头像**。
- 此功能是旧版本搭配**沉浸扮演模式**使用的。在新版本中，此功能并无设置意义，但为了个性化区分，并未移除。

## 7.2 主题与显示设置

你可以在**主题页**中设置：

- 配色
- 预测性返回手势
- 字体字号
- 语言
- 刷新率
- 流式对话动画
- 聊天背景

| 设置 | 说明 | 新手建议 |
| --- | --- | --- |
| 主题模式 | 浅色 / 深色 / 跟随系统 | 跟随系统最省心 |
| Material You | 动态配色（只调颜色不动布局） | 喜欢就开 |
| 字体大小 | 实时预览，可跟随系统或自定义 | 按眼睛舒服程度调 |
| 刷新率 | 系统智能 / 30 / 60 / 90 / 120 Hz | 默认「系统智能」即可，最终取决于屏幕硬件 |

::: warning 动态配色
动态配色（Material You）仅支持 **Android 12 及以上**设备，低于此版本修改不生效。
:::

## 7.3 系统提示词

- 本软件内置**默认提示词**，通常情况下不需要你额外修改。
- 如果你需要**角色扮演**、或非编程等其他需求，可以**新增**你的提示词。
- 系统提示词决定了 AI 的**自我认知**，期望向 AI 询问"你是什么模型"来获取正确模型名是不实际的。
- 你可以通过查看源码、逆向应用或者直接向 AI 询问获取本应用的原生提示词。
