# 模型配置

对话模型配置请参考[快速上手](/guide/quick-start)完成。本条目指导你如何配置**额外功能模型**和对话模型的**高级配置**。

## 额外功能模型

### 话题总结模型

你在新对话中发送首条信息后，应用会将该条消息作为对话标题。你可以在 **设置页 → 额外功能模型 → 话题总结模型** 中选择一个模型用于总结标题。

### 会话历史压缩模型

在多轮对话后，单个会话窗口积攒的上下文会越来越多，这会导致：

- Token 消耗增长
- 响应变慢
- 超出 API 限制返回错误

你可以在 **设置页 → 额外功能模型 → 会话历史压缩模型** 中设置历史压缩模型，对上下文进行压缩。

## 高级配置

高级配置需要你参考你使用的服务商的 **API 文档**进行配置。不同的服务商可能有不同的：

- Base URL
- 路径（Path）
- Responses API 的支持情况

::: tip 提示
- 部分服务商可能不支持获取模型列表，此时可以手动填写模型名称。
- 如果你使用自定义服务商，需要自行确认其接口是否与 OpenAI Chat Completions、Anthropic Messages API 或 Gemini GenerateContent API 兼容。
:::
