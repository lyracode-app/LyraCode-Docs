# 第 19 章：记忆与指令——让稳定偏好跨对话生效

## 19.1 记忆是什么

记忆是额外提供给 AI 的本地个性化信息，用于保存未来多个对话仍有帮助的稳定偏好、沟通方式和工作习惯。

适合保存：

- “默认使用简体中文回答”；
- “教程先解释术语，再给编号步骤”；
- “代码审查优先关注数据丢失风险”；
- “我使用 Windows PowerShell”。

不适合保存：

- API Key、密码、私钥；
- 今天临时要做的一件事；
- 某次任务的进度；
- 未经确认的敏感个人信息；
- 很快会过期的模型价格或版本状态。

## 19.2 手动添加记忆

1. 打开 **设置 → 记忆**。
2. 点击 **添加记忆**。
3. 用简洁陈述写一项偏好。
4. 选择分类：个人偏好、工作风格、沟通方式、个人信息或其他。
5. 保持“用于个性化”开启。
6. 保存。

一条记忆只写一个主题，便于以后修改。例如不要把语言、编程风格、时区和三个项目规则塞在同一条。

## 19.3 在对话中让 AI 记住

可以说：

> 请记住：以后给我的零基础教程都先解释术语，再列编号步骤。

AI 应调用保存记忆工具。看到工具记录后，再说“列出你保存的相关记忆”进行核对。不要只凭 AI 口头说“我记住了”。

## 19.4 修改、停用和删除

- **修改**：纠正内容或分类；
- **停用**：保留条目，但不再提供给 AI，适合暂时不用；
- **删除**：永久移除不再适用的内容。

既可以在设置页操作，也可以明确要求 AI 修改或忘记某条记忆。为了避免删错，先让它列出相关记忆和 ID，再指定目标。

## 19.5 记忆会怎样发送

启用的记忆会作为额外提示信息提供给模型，用于理解你的长期偏好。它保存在本机，但当模型处理对话时，相关内容会随请求发送到你配置的模型服务商。

因此“本地保存”不代表“永远不离开手机”。秘密不应写进记忆。

## 19.6 系统提示词、记忆和项目规则的区别

| 类型 | 适用范围 | 适合内容 |
| --- | --- | --- |
| 系统提示词 | 选中它的对话 | 角色、回答风格、通用任务规则 |
| 记忆 | 跨对话个性化 | 稳定的个人偏好和工作习惯 |
| `AGENTS.md` | 某个项目目录 | 构建命令、代码规范、目录约定 |
| 当前用户消息 | 当前任务 | 本次目标、范围和临时要求 |

不要把项目的构建命令存成全局记忆；应写进项目 `AGENTS.md`。不要把一次性输出格式做成永久记忆；直接在当前消息说明。

## 19.7 指令发生冲突怎么办

用户当前明确要求通常比旧的个性化偏好更具体。项目规则只在对应目录生效。无论来自哪里，指令都不能要求泄露密钥、伪造结果或绕过安全审批。

发现 AI 反复遵循旧偏好时：

1. 打开设置页搜索相关记忆；
2. 修改、停用或删除；
3. 检查当前系统提示词；
4. 检查工作区里的 `AGENTS.md`；
5. 新建会话重新测试。

## 19.8 备份与隐私

记忆默认可纳入数据备份，也可在导出时单独取消。把备份交给别人前，即使不含 API Key，也要检查记忆中是否有个人信息、内部项目名称或工作习惯。

## 19.9 常见问题

### 为什么 AI 没按记忆回答

检查条目是否启用、内容是否清楚、是否与当前直接要求冲突。还要确认模型是否很好地遵循系统指令。

### 为什么它保存了不该保存的内容

在设置页删除，并在当前对话明确说明此类信息只用于本次任务。敏感内容若已发给外部模型，还应按服务商隐私与日志策略处理。

### 删除记忆会删除旧聊天吗

不会。删除只影响记忆条目，旧会话里已经出现的文本仍在对话历史和可能的备份中。
