# 第 2 章：认识界面，配置你的第一个 AI 模型

> 本章教你看懂 Lyra Code 的界面，并完成**最关键的一步：把 AI 服务商接进来**。配置好之后，你就能真正开始和 AI 对话了。
>
> 预计阅读 15 分钟。

---

## 3. 界面总览：App 里有哪些区域？

Lyra Code 打开后，主要分为 **四大区域**。你可以通过底部的导航栏在它们之间切换。

### 3.1 AI 对话页（你的主战场）

这是你 90% 时间待的地方，也是与 AI 交流的窗口。

**你会看到：**

- **上方的对话区**：你和 AI 一来一往的消息记录；
- **底部的输入框**：在这里打字，回车发送；
- **底部动作面板**：一排快捷按钮，可以快速切换**服务商 / 模型 / 系统提示词**（具体见第 4 节）。

**新手第一句话可以试试：**

> 你好，介绍一下你自己，以及你能帮我做什么？

AI 会回复一段自我介绍。到这里，你就算「跑通」了整条链路。

### 3.2 双栏文件管理器（你的文件仓库）

点开文件管理器，你会看到**左右两个窗口**（所以叫"双栏"），默认都在手机存储根目录 `/storage/emulated/0`。

- **左右两栏独立导航**：左边选中一个文件夹，右边选另一个，方便两边对照；
- **跨目录操作**：把文件从左边**复制/移动到**右边，或者重命名、删除、解压；
- **网页预览**：**长按** `.html` / `.htm` 文件，可以调用浏览器预览（比如预览你做的网页）。

::: tip 新手提醒
文件管理器里的操作都是「真刀真枪」的——删除不可恢复（除非有 `.bak` 备份）。**操作前看清楚路径**，不确定就先用 AI 问一下。
:::

### 3.3 代码编辑器（Sora Editor）

点开一个文本/代码文件，就会进入编辑器：

- **行号**：左侧的数字，方便定位；
- **语法高亮**：代码会自动上色（关键词一个颜色、字符串一个颜色），读起来更清楚；
- **文件内搜索**：在当前文件里查找关键词；
- **跳转行**：输入行号直接跳过去；
- **自动换行**：长行不超出屏幕；
- **自动备份**：**修改文件前，自动在原目录生成一个 `.bak` 备份文件**（比如 `main.kt` 会被备份成 `main.kt.bak`）。改坏了可以从备份恢复——这是你的后悔药，别删。

> 如果打开的文件编码不是 UTF-8，编辑器会警告，属于正常提示。

### 3.4 Agent 工具页（AI 的"工具箱"）

这里列出 AI 当前**能用哪些工具**（读文件、跑命令、发邮件……），以及每个工具的开关。

- 新手**保持默认全开**即可；
- 等以后熟悉了，可以把不信任的工具单独关掉（比如你不想让 AI 动 Root，就把 Root 工具关掉）。

### 3.5 编辑器内的 AI 侧栏（边看代码边让 AI 改）

在代码编辑器里，**用手指从右往左滑动**，会打开一个专用的 AI 对话侧栏。它和主对话的区别：

- AI **自动知道**你当前打开的是哪个文件，直接针对这个文件回答/修改，不用你再描述路径；
- 你可以把项目文件夹加进来，让 AI 了解整个项目；
- AI 的修改会以**可视化方式回放**在文档里，你能清楚地看到它改了什么（绿色=新增，红色=删除）。

**这是「边看代码边让 AI 干活」最顺手的入口**，比在全局对话里发路径更精确。

### 3.6 快速上手三步（完整版）

1. **接模型**：在设置里添加你的 AI 服务商（怎么填，见下面第 4 节）；
2. **建工作区**：通过文件管理器（或让 AI）在 `/storage/emulated/0/Lyra` 下创建你的项目文件夹；
3. **开始对话**：试着对 AI 说「列出工作区内容」「创建一个 TODO」「修改某个文件」，观察它每一步先弹出确认框等你批准——这就是 Agent 的工作方式。

## 4. 模型与多服务商配置（最关键的一节）

### 4.0 先搞懂三个词

- **服务商（Provider）**：提供 AI 模型的公司/平台，比如 OpenAI、DeepSeek、Moonshot（Kimi）、Google；
- **模型（Model）**：服务商旗下具体的大脑版本，比如 `gpt-4o`、`deepseek-chat`、`kimi-k2`；
- **Base URL**：服务商的服务器地址，一般是一串网址。**用官方服务商通常不用填**（App 内置了默认地址），只有用第三方网关或自己搭建的服务器才需要填。

### 4.1 Lyra Code 支持哪几类服务商？

| 协议 | 怎么理解 | 常见服务商 |
| --- | --- | --- |
| OpenAI 兼容接口 | 行业通用标准，绝大多数服务商都支持 | OpenAI、DeepSeek、Moonshot、本地 Ollama/vLLM 等 |
| Anthropic Messages API | Claude 专用接口 | Anthropic（Claude 系列） |
| Gemini GenerateContent API | Google 专用接口 | Google（Gemini 系列） |

**新手建议**：优先选一家「OpenAI 兼容」的国内服务商（如 DeepSeek、Moonshot），便宜、稳定、网络友好。

### 4.2 添加服务商：一步步来

1. 打开 **设置页** → 找到 **「模型服务商」**（或类似入口）；
2. 点 **「添加 / 新增」**；
3. 按表格填写（见 4.3）；
4. 保存后，回到对话页，**在底部动作面板里选中刚添加的服务商和模型**；
5. 发一句「你好」测试。

**能成功收到回复，就说明配置完成。** 如果报错，看下面的 4.5。

### 4.3 每个配置项是什么意思？

| 配置项 | 填什么 | 举个例子 | 新手提示 |
| --- | --- | --- | --- |
| 服务商名称 | 随便起个方便认的名字 | `我的DeepSeek` | 多个服务商时靠它区分 |
| API Key | 服务商后台生成的密钥 | `sk-xxxx...` | **只存本机；别泄露** |
| Base URL | 服务商服务器地址 | `https://api.deepseek.com` | 官方服务商一般不填 |
| 预设模型 | 你想用的模型名 | `deepseek-chat` | 填服务商文档里的准确名称 |
| 自定义系统提示词 | 设定 AI 的人设/规则 | 「你是一位严谨的中文编辑」 | 可以存多套，随时切换 |
| 推理深度 | 推理类模型（如 o 系/R 系）的思考强度 | 低/中/高 | 非推理模型无需设置 |

### 4.4 多服务商切换技巧

- 对话页底部的**动作面板**支持一键切换：**服务商 / 模型 / 提示词**；
- **比效果**：同一个问题，先切到 A 模型问一次，再切到 B 模型问一次，对比哪个回答好；
- **分场景**：编码用一个提示词（"你是资深 Kotlin 工程师"），写作用另一个（"你是小说作者"），切换提示词就能改变 AI 的行为风格；
- **私有化部署**：如果你自己电脑上跑着 Ollama / vLLM / LM Studio，它们也走 OpenAI 兼容协议——Base URL 填你的局域网地址（如 `http://192.168.1.5:11434/v1`）即可，完全免费、数据不出门。

### 4.5 新手常见问题 FAQ

**Q：添加后一直报错/转圈？**
A：按顺序检查：① API Key 复制全了吗（别带空格）；② 服务商名称和模型名写对了吗；③ 网络能访问该服务商吗；④ Base URL 填对了吗（官方服务商留空）。

**Q：提示 401 / 认证失败？**
A：API Key 无效或已过期。去服务商后台重新生成一个，替换掉。

**Q：提示额度不足 / insufficient balance？**
A：账户没钱了。去服务商官网充值（一般几块钱能用很久）。

**Q：哪个服务商便宜？**
A：价格变化快，建议用「OpenAI 兼容」的国内平台对比，或者看第 14 章用量统计自己测。

**Q：可以同时添加多家吗？**
A：可以，随便加，数量不限。切换只在对话页底部点一下。
