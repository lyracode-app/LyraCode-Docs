### 同步与加载

每次加载十个版本，可继续“加载更多版本”。记录在浏览器缓存五分钟；网络或接口限流时显示已有缓存并标明状态，可点击重试。没有可用缓存时仍可前往 [GitHub 发布页](https://github.com/lyracode-app/Lyra-Code/releases)，镜像可查看 [Gitee 发布页](https://gitee.com/yukisoffd/lyra-code/releases)。

## 如何核对功能

1. 在应用的关于页面查看已安装版本及构建类型。
2. 对照上方该版本的发布说明，确认功能是否包含在对应构建中。
3. 检查模型能力、工具开关、权限与已启用的环境。
4. 仍有差异时，按[排障信息清单](/reference/troubleshooting)记录可复现步骤。

## 本站适用范围

文档随应用源码维护；上方 Release 列表展示已发布版本，两者的更新节奏可能不同。Debug/Beta 构建也可能与正式版存在差异，应以安装版本及对应发布说明核对，不能只根据页面中的某个固定版本号判断。

站点提供[用户操作](/manual/)、[应用开发](/developer/)、[可复用示例](/examples/)和[参考资料](/reference/)四类内容。文档维护规则见[维护文档站](/developer/documentation)。
