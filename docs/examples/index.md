# 选择一个示例

这些示例分别覆盖用户操作与扩展开发。源文件随站点提供，可下载后检查；其中 MCP 配置需要替换地址和凭据，Android 运行行为需要在你的设备验证。

| 示例 | 前置条件 | 产物与成功标志 |
| --- | --- | --- |
| [静态网页](/examples/static-site) | 已选工作区、微型服务器 | 页面可打开，计数按钮可工作 |
| [项目修复](/examples/project-repair) | 已有项目和可运行的相关测试 | 可复现的问题消失，Diff 与测试结果可核查 |
| [项目检查 Skill](/examples/skill) | Skills 导入入口、可用工具模型 | Agent 读取流程和清单，产出检查报告 |
| [HTTP MCP](/examples/mcp) | 实际 HTTP MCP 服务和鉴权 | 获取工具列表，完成一次只读调用 |
| [API 2 桌宠](/examples/pet) | 已启用桌宠的 Android 应用 | 导入后显示状态球，颜色与任务状态可变化 |

第一次使用建议先完成[快速上手](/manual/quick-start)，再按本表顺序学习。扩展机制的选择见[开发指南](/developer/extensions)。
