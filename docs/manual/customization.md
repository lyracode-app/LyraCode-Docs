# 外观与内容显示

本页介绍阅读外观与富媒体。可复用流程见[Skills](/manual/skills)，长期规则见[自定义指令与记忆](/manual/memory)。

## 外观设置

根据需要调整主题、背景和字体；修改后检查正文、代码与审批卡片的可读性。背景遮罩和颜色应在长对话与代码页分别检查。

## 富媒体

### Markdown 与公式

对话可展示标题、列表、表格、代码和 LaTeX。显示正确不等于程序或计算正确，仍需核对来源与结果。

### 图片、SVG 与图表

图片、SVG 与多种图表可按界面提供的选项全屏查看或导出。静态 SVG 预览不支持滤镜和 `foreignObject`；动画 SVG 使用不同渲染路径，脚本与外部资源不会执行或加载。图表导出的格式以实际菜单为准。

## 搜索显示与后端

联网搜索可配置后端及网站黑名单。内置后端的根域名与子域名需分别设置；DeepSeek Search/Fetch 行为与内置黑名单不同，以设置说明为准。
