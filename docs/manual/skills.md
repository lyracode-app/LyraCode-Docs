# Skills 导入与使用

Skill 是可复用的任务流程，以 `SKILL.md` 为入口，可包含清单和示例。它提供操作说明，所需工具、依赖与权限仍要分别配置。

## 导入

在 Skills 页面导入 Markdown、包含 `SKILL.md` 的 ZIP，或支持的仓库/原始文件地址。检查名称、说明、正文与参考文件，确认用途后启用。先尝试[项目检查示例](/examples/skill)。

## 在对话中使用

说明任务目标，也可用界面提供的本轮 Skill 选择功能明确指定。Agent 按需读取入口与参考文件；检查工具记录确认实际读取了对应内容。

### 示例提示

> 使用项目检查 Skill，只读检查当前工作区的构建入口与测试配置，报告找到的命令及依据。

### 验证结果

Skill 被选中不表示任务完成。继续检查文件、命令结果与验收要求。包内脚本也不会因导入而自动执行。

## 管理与更新

不再需要时停用或删除；更新后重新检查正文和适用条件。避免多个 Skill 对同一任务给出冲突流程。来源不明且要求无关凭据或目录的内容，不应视作授权。

长期偏好见[指令与记忆](/manual/memory)，作者开发入口见[扩展与加载](/developer/extensions)。
