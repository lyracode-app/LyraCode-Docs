# 终端：本地 Linux 与 SSH

目标：在应用内直接操作本机 PRoot Linux 或远程 SSH 主机，确认键盘输入、画面输出和会话保持是否符合预期。Agent 侧的同类能力见 [PRoot、Termux 与命令](/manual/commands)。

## 打开终端

主导航中的「SSH 终端」页就是终端页。页面顶部的目标选择器按顺序列出：

1. 已启用的 PRoot Linux 环境，显示为「环境名 · Linux ID」。
2. 已启用的 SSH 服务器，显示配置时的名称。

选中目标后点「连接」。已连接时按钮变为「断开」。没有任何已启用环境或服务器时，选择器位置提示没有可用服务器，此时先到 [PRoot Linux 设置](/manual/commands)或 [SSH 配置](/manual/remote-services)启用一项。

## 本地 Linux 会话

本地目标是 PRoot 环境里的交互式 shell，不经过 SSH。

- 每个环境有一个独立会话。切到其他页面、返回对话或切换到别的目标后，shell 里的作业和编辑器继续运行。
- 会话在应用运行期间保留；在设置中禁用该环境或删除它时，会话随之结束。
- 工作目录与 Agent 的 `proot_command` 属于同一个环境：同一个 rootfs、同一套挂载。已选工作区出现在 `/workspace`，共享存储挂载到 `/storage` 和 `/sdcard`。
- 终端会话和 Agent 调用是彼此独立的进程。它们共享文件和挂载，但不共享 shell 变量、当前目录和后台作业；不要在终端里手工执行一条长命令的同时让 Agent 在同一个目录跑构建。

环境尚未准备好、rootfs 缺失或权限变化后，先按[命令页](/manual/commands)的步骤检查环境，再回到终端重连。

## 远程 SSH 会话

远程目标先要有可用的服务器配置，凭据与主机信息见 [SSH 与远程文件传输](/manual/remote-services)。

状态提示对应实际连接阶段：

| 提示 | 含义 |
| --- | --- |
| 正在建立安全连接… | 已发起握手与认证 |
| 已安全连接 | 认证完成，可以输入命令 |
| 连接中断，正在进行第 N 次重连… | 断线后自动重连，间隔随次数递增 |
| 已断开 | 手动断开或重连放弃 |
| 服务器主机密钥已变化，为保障安全已拒绝连接 | 远端指纹与保存值不一致，需先核对再处理 |
| 身份验证失败，请检查用户名和凭据 | 密码或私钥不被接受 |
| 连接超时，请检查服务器和网络 | 网络不可达或远端无响应 |

主机密钥变化不会自动接受，也不会被静默忽略。确认是远端正常更换密钥后，再更新该服务器配置；来源不明的指纹变化应先停止使用该主机。

长时间运行的任务依赖 SSH keepalive 和有限次数的自动重连。重连后原有的前台进程可能已结束，回到 shell 时先用 `pwd`、`jobs` 或进程检查确认当前状态，不要假定命令仍在运行。

## 输入、复制与链接

终端下方有两排附加键，用于补齐软键盘缺少的按键：

- 第一排：`Esc`、`/`、`-`、`Home`、`↑`、`End`、`PgUp`。
- 第二排：`Tab`、`Ctrl`、`Alt`、`←`、`↓`、`→`、`PgDn`。

`Ctrl` 和 `Alt` 是粘滞修饰键，点亮后与下一个按键组合，例如 `Ctrl` 加 `c` 发送中断。物理键盘可直接使用。

- 长按并拖动可选择文本，状态栏提供复制。
- 「粘贴」写入剪贴板内容，「清空终端」只清理当前可见画面与回滚缓冲，不结束会话。
- 画面上识别到的网址显示为链接，点击后弹出对话框，可把地址复制到剪贴板。

## 外观设置

终端字体、字号与配色在设置的外观页中调整：

1. 打开「设置 → 外观与显示 → 字体与大小」。
2. 在字体库下方的终端区域选择字体；应用不内置终端字体，默认使用系统等宽字体，推荐 Maple Mono、JetBrains Mono 等等宽字体。
3. 拖动字号滑块，范围 8–28 sp。
4. 选择配色：Campbell 或 Solarized Dark，下方色带显示 16 个 ANSI 颜色的实际取值。

配色只决定索引颜色的解析方式，程序输出的 24 位真彩色不随配色改变。修改后回到终端检查中文、框线和 ANSI 颜色是否正常显示。

**成功标志：** 本地目标能执行 `pwd` 并返回预期目录；SSH 目标能执行 `uname -a`；附加键、复制粘贴和中文显示均正常。

## 常见问题

- **本地目标不出现：** 环境未启用或仍在准备中。回到设置启用后再打开终端页。
- **重连后命令像是没在跑：** 断线期间前台进程可能已终止，重新检查进程状态，必要时重新启动。
- **中文显示为方块：** 在 Linux 内安装中文字体，或在字体库中选择覆盖这些字符的字体。
- **粘贴带出多余换行：** 多行内容会被逐行执行，先确认每条命令再粘贴。
- **需要把终端里的路径给 Agent：** 直接引用绝对路径；Agent 的 `proot_command` 与终端处于同一环境，能看到相同文件。
