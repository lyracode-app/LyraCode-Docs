# 对话跳转与快捷手势

长对话可以按用户轮次跳转，不必连续滚过工具记录。导航仅改变阅读位置，不会发送消息或创建分支。

## 显示跳转控件

在消息区向左滑动可唤出右侧跳转控件，显示后及时点击；约 2.6 秒未操作会自动隐藏，点击会重新计时。没有消息时不显示。手势需明显偏向水平方向；若没有出现，在消息列表空白处左滑，避免与卡片自身的横向手势冲突。

## 四种跳转

| 控件 | 目标 | 对自动跟随的影响 |
| --- | --- | --- |
| 双上箭头 | 对话顶部 | 暂停自动跟随 |
| 上箭头 | 当前可见位置之前的一条用户消息 | 暂停自动跟随 |
| 下箭头 | 当前可见位置之后的一条用户消息 | 暂停自动跟随 |
| 双下箭头 | 对话底部 | 恢复跟随最新输出 |

上一条/下一条按用户消息定位，因此会跨过中间的回复和工具过程。越过首尾时到达顶部或末尾。

## 消息菜单与卡片手势

### 用户消息长按

打开用户消息菜单后，可以使用界面提供的编辑并重新生成、创建分支等操作。重新生成会影响后续对话，想保留另一条思路时先[创建分支](/manual/conversation-branches)。

### TODO 和文件变更卡片左滑

卡片可折叠查看；向左滑动可隐藏当前一组进度或变更展示。隐藏只影响展示，不会撤销修改或删除历史；后续新状态可能再次显示卡片。文件修改结果仍应在[变更审查](/manual/review)中核对。

## 阅读历史时输出跳动

手动向上阅读会暂停自动跟随。需要回到实时输出时使用“回到底部”，或滚动至底部。停止跟随不会停止模型生成；要中断执行，应使用对话的停止操作。
