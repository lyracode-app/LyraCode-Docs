# 第三方账号

“第三方账户”目前提供梦汐 API 平台账号和 ChatGPT 账户入口。普通模型服务商仍可在[模型配置](/manual/models)中手动添加，无需先登录第三方账户。

## 梦汐 API

### 登录与注册入口

从侧栏个人资料入口，或设置中的个人资料页，找到“第三方账户 → 梦汐 API”。未登录时可登录或注册；已登录时进入账号详情。

#### 登录

填写平台用户名和密码；账号启用两步验证时，继续填写验证码。应用不保存密码，登录 Cookie、用户信息和服务 Key 存在设备内。

#### 注册

按页面填写用户名、密码、邮箱与邮件验证码，可填写邀请码。发送验证码和注册是否成功取决于平台状态与规则，以实际返回为准。

### 同步模型服务

登录后应用尝试同步平台 Key 与模型列表。账号页显示已配置 Key 数和模型数，可手动再次“同步”。同步可能复用或创建应用管理的 Key；它不会增加账号余额。

同步后到模型服务中核对配置、选中可用模型并发起小请求。若已有可用模型服务，账号同步不一定自动切换当前选中项。

### 额度与请求次数

账号页可刷新剩余额度、已用额度和请求次数；这些是平台返回的数据。侧栏[统计](/manual/statistics)是本地记录，两者覆盖范围与统计口径可能不同。“Key 无限额度”也仍受账号实际余额限制。

### 退出、备份与数据范围

退出会清除本地登录态并尝试注销平台会话；已配置的模型服务和 Key 保留，需要到模型服务中手动移除。账号登录态不进入应用备份或系统迁移，换设备后重新登录。模型 Key 仅在备份勾选包含密钥时导出。

账号同步不上传本地对话、附件和其他设置；使用该平台模型时，请求内容发送到该平台。页面提供平台网站入口以查看其说明。

## ChatGPT

### 登录与新增账户

从侧栏个人资料入口，或“设置 → 个人资料 → 第三方账户”，进入 ChatGPT 账户页。首次使用点击“使用 ChatGPT 继续”；已有账户时点击“新增其他账户”，在独立登录页选择登录方式，并在系统浏览器中完成 OpenAI 授权。

- **ChatGPT 官方登录（SIWC）：** 使用 OpenAI 为开源应用提供的订阅授权流程。
- **Codex 兼容登录：** 使用独立的 Codex 授权及私有接口，需要单独登录。接口可能被 OpenAI 更改或限制。

登录成功后返回账户页，并尝试同步、启用该账户的模型服务。同步失败时登录态保留，可在账户页再次同步。多个账户或工作区分别保存；“重新授权此账户”会进入该账户对应的登录流程。

### 账户页与模型服务

邮箱、订阅计划、5 小时额度、每周额度采用 2×2 卡片展示。额度卡片的圆环中央显示剩余百分比，底部显示重置时间；无适用的 5 小时限制时显示“无该时间限制”。页面右上角的圆圈感叹号按钮可查看服务、隐私和用量说明。

ChatGPT 订阅不提供此接入所需的 API Key。模型列表由当前授权账户同步，请求固定使用 Responses；此类服务不显示 API Key、高级配置、自定义地址和请求覆盖设置，也不用于媒体生成。模型服务列表和对话中的服务商选择列表均显示 ChatGPT logo。

### 对话中的剩余额度

输入框上方显示“正在使用 ChatGPT 订阅 · 5 小时剩余：…”，无适用的 5 小时限制时改为显示每周剩余额度。该提示不含“管理用量”按钮；详细用量和管理入口仍可在账户页查看。

额度低于 10% 不弹出预警。额度来自 OpenAI 实际返回的数据，Codex 模式会在应用可见时约每分钟、打开账户页及请求前按缓存状态刷新。官方 SIWC 可能不提供完整用量数据；缺失、过期或窗口重置后显示“暂不可用”，不代表满额，也不保证新请求必定获准。

任一适用窗口额度耗尽或服务拒绝继续使用时，任务暂停并提示用量限制。对话、已生成内容和已完成的工具操作记录会保留；额度恢复后，或选择其他模型服务后，可在原对话中点击“继续”。暂停不会撤销已完成的外部操作。

### 凭据、退出与服务规则

授权在系统浏览器中完成，Lyra Code 不获取 ChatGPT 密码或既有 ChatGPT 聊天记录。OAuth 凭据在设备本地加密保存，不进入应用备份、模型配置、请求预览或 HTTP 审计导出。账户和用量查询、模型请求直接连接 OpenAI；使用模型时，所选上下文、工具结果及请求包含的附件会发送给 OpenAI。

退出会停止该账户的任务、清除本地凭据并尝试撤销远程会话。对话记录和服务配置保留；继续使用该账户需重新授权。若提示远程撤销未确认，请到 ChatGPT 设置中断开此应用。

该服务由 OpenAI 提供，可能随时变更、限制或停止。授权订阅仅可在 Lyra Code 内按 ChatGPT 条款和政策使用；不得转售、共享凭据、滥用或用于被禁止的行为，否则可能导致 ChatGPT 账户受到官方警告、限制甚至停用。

## 常见问题

- **登录成功但同步不完整：** 查看同步提示，进入账号页再次同步；分别检查 Key 和模型列表。
- **梦汐 API 退出后仍能调用模型：** 检查保留的服务配置与 Key，需要停用时手动移除。
- **余额有值但模型请求失败：** 检查模型 ID、Key 权限、平台响应与网络，见[日志](/manual/logs)。
- **ChatGPT 用量显示暂不可用：** 在账户页尝试刷新；服务未返回、数据过期或刚重置时都可能出现此状态。
- **ChatGPT 登录成功但没有模型：** 在账户页重试同步，并检查订阅授权及 OpenAI 实际返回的错误；普通 API Key 不适用于这个账户入口。
