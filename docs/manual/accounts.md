# 第三方账号

「第三方账户」提供三类登录入口：New API 兼容登录、ChatGPT 和 DeepSeek Harness。普通模型服务商仍可在[模型配置](/manual/models)中手动添加，无需先登录第三方账户。三类入口可以同时使用，彼此独立。

## 入口与共同规则

从侧栏个人资料入口，或「设置 → 个人资料 → 第三方账户」进入，列表中依次是 New API、ChatGPT、DeepSeek Harness。

- 每个入口在已登录后显示账号名称，未登录时显示对应的登录提示。
- 登录态只在设备本地保存，不进入应用备份、Android 云备份或设备迁移；换设备后需要重新登录。
- 退出登录不等于删除已同步的模型服务，需要到模型服务设置中手动移除。
- 账号页只负责登录、同步和额度查询；对话中选用的模型仍由模型服务列表决定。

## New API 兼容登录

### 与旧版梦汐 API 的差别

旧版账号绑定单一梦汐平台。现在改为通用的 New API 兼容登录：登录前填写站点地址，任何提供 New API 兼容接口并支持密码登录的站点都可以使用。

- 站点地址必须是以 `https://` 或 `http://` 开头的完整地址，作为账号的一部分保存。
- 更换站点等于更换账号，已同步的模型服务按各自的站点分别存在。
- 升级后，原「梦汐 API · …」名称的模型服务会显示为「New API · …」，配置本身保留。
- 站点要求其他登录方式（如单点登录、扫码）时，应用内的密码登录不适用，请直接访问该站点。

### 登录

1. 进入「第三方账户 → New API 兼容登录」，点「登录 / 注册」。
2. 填写站点地址、用户名和密码。
3. 账号启用两步验证时，按提示输入身份验证器中的动态验证码或备用码。

勾选「记住账密」后，账密加密保存在本机，下次登录时自动填入。「自动登录」需要先记住账密：应用启动时检查登录态，失效时用保存的账密再次登录。二步验证始终需要手动完成。本机加密存储不可用时会提示仍可登录，但无法记住账密。

### 注册

在同一页切换到注册模式，填写用户名、密码、邮箱与邮件验证码，可填写邀请码。邮箱等字段是否必填由站点决定。注册成功后用新账号登录。

发送验证码和注册是否成功取决于站点状态与规则，以实际返回为准。

### 同步 Key 与模型

登录后应用尝试同步账号的 API Key 与模型列表，可随时点「同步 Key 与模型」重试，或「刷新用户信息」更新账号资料。

- 账号页显示 Key 数量与模型数量。
- 同步可能复用或创建应用管理的 Key；它不会增加账号余额。
- 只在部分成功时，页面提示可继续同步，此时先核对已同步的 Key 和模型，再发起请求。

同步后到模型服务中核对配置、选中可用模型并发起小请求。已有可用模型服务时，同步不一定会自动切换当前选中项。

主 Key 优先使用；遇到 HTTP 401、402、403、429 时按顺序尝试已添加的副 Key。副 Key 只是降级手段，不改变站点侧的权限和额度。

### 账号信息与额度

账号页显示用户 ID、显示名称、用户分组、账户余额、已用金额和请求次数。金额按站点配置的比例和币种换算，缺少换算信息时显示「—」。

侧栏[统计](/manual/statistics)是本地记录，两者覆盖范围与统计口径不同。“Key 无限额度”也仍受账号实际余额限制。

### 退出与数据范围

「退出平台账号」会关闭自动登录、清除本地登录态并尝试注销站点会话；已记住的账密保留供下次手动登录，已配置的模型服务和 Key 同样保留。

账号登录态与记住的账密不进入应用备份或系统迁移。主副模型 Key 仅在备份勾选包含密钥时导出。账号同步不上传本地对话、附件和其他设置；使用该站点的模型时，请求内容发送到该站点。页面提供站点入口以查看其说明。

## DeepSeek Harness

### 登录

1. 进入「第三方账户 → DeepSeek Harness」，点「使用 DeepSeek Harness 登录」。
2. 在系统浏览器完成 DeepSeek 官方平台的授权。
3. 授权后回到应用，等待本机回调完成凭证换取。

应用用授权码与设备标识换取专用凭证，因此不需要填写 API Key 或密码。登录请求有 5 分钟超时；找不到浏览器、本机回调端口被占用或授权数据不完整时都会给出对应提示，重新发起即可。

### 模型服务

登录成功后应用为该账号建立专用模型服务，并同步可用模型列表。该服务走 DeepSeek 的 Anthropic 兼容接口，请求结构由授权方式固定：

- 不显示 API Key、高级配置、自定义地址和请求覆盖设置，也不支持[自定义模型请求](/manual/request-customization)。
- 模型列表由账号返回，可在账号页刷新；刷新失败时原有模型配置仍可使用。
- 登录失效时提示重新登录，重新登录后无需重建模型服务。

### 余额与低余额告警

账号页显示充值余额与赠金余额，可手动刷新；读取失败且已有上次数据时，会标注这是上一次获取的余额。金额不可用不代表满额，也不代表余额为零。

页面提供「查询用量」与「充值」，两者都在 DeepSeek 平台完成。

「低余额告警」可以按币种设置阈值并开启通知：充值余额低于阈值时提醒一次，恢复到阈值以上后再次跌破才会再次提醒。开启需要授予 Android 通知权限，未授予时页面提供通知设置入口。开启告警后，应用会定期查询充值钱包。

### 退出与服务规则

退出会清除本机凭证并尝试在 DeepSeek 平台注销会话。平台退出请求失败时，提示已在本机退出，此时如需彻底断开，请到 DeepSeek 平台处理。

凭证加密保存在本机，不进入应用备份，也不出现在模型配置、请求预览和 HTTP 审计导出中。使用该服务时，所选上下文、工具结果及请求包含的附件会发送给 DeepSeek；账号查询与模型请求直接连接 DeepSeek，适用其协议与隐私政策。

服务由 DeepSeek 提供，可能随时变更、限制或停止。不要共享或转售凭证，也不要把该登录用于被禁止的用途。

## ChatGPT

### 登录与新增账户

从同一入口进入 ChatGPT 账户页。首次使用点击“使用 ChatGPT 继续”；已有账户时点击“新增其他账户”，在独立登录页选择登录方式，并在系统浏览器中完成 OpenAI 授权。

- **ChatGPT 官方登录（SIWC）：** 使用 OpenAI 为开源应用提供的订阅授权流程。
- **Codex 兼容登录：** 使用独立的 Codex 授权及私有接口，需要单独登录。接口可能被 OpenAI 更改或限制。

登录成功后返回账户页，并尝试同步、启用该账户的模型服务。同步失败时登录态保留，可在账户页再次同步。多个账户或工作区分别保存；“重新授权此账户”会进入该账户对应的登录流程。

### 账户页与模型服务

邮箱、订阅计划、5 小时额度、每周额度采用 2×2 卡片展示。额度卡片的圆环中央显示剩余百分比，底部显示重置时间；无适用的 5 小时限制时显示“无该时间限制”。页面右上角的圆圈感叹号按钮可查看服务、隐私和用量说明。

ChatGPT 订阅不提供此接入所需的 API Key。模型列表由当前授权账户同步，请求固定使用 Responses；此类服务不显示 API Key、高级配置、自定义地址和请求覆盖设置，也不用于媒体生成。模型服务列表和对话中的服务商选择列表均显示 ChatGPT logo。

### 对话中的剩余额度

输入框上方显示“正在使用 ChatGPT 订阅 · 5 小时剩余：…”，无适用的 5 小时限制时改为显示每周剩余额度。该提示不含“管理用量”按钮；详细用量和管理入口仍可在账户页查看。

额度低于 10% 不弹出预警。额度来自 OpenAI 实际返回的数据，Codex 模式会在应用可见时约每分钟、打开账户页及请求前按缓存状态刷新。官方 SIWC 可能不提供完整用量数据；缺失、过期或窗口重置后显示“暂不可用”，不代表满额，也不保证新请求必定获准。

任一适用窗口额度耗尽或服务拒绝继续使用时，任务暂停并提示用量限制。对话、已生成内容和已完成的工具操作记录会保留；额度恢复后，或选择其他模型服务后，可在原对话中点击“继续”。暂停不会撤销已完成的外部操作。

### 凭据、退出与服务规则

授权在系统浏览器中完成，Lyra Code 不获取 ChatGPT 密码或既有 ChatGPT 聊天记录。OAuth 凭据在设备本地加密保存，不进入应用备份、模型配置、请求预览或 HTTP 审计导出。账户和用量查询、模型请求直接连接 OpenAI；使用模型时，所选上下文、工具结果及请求包含的附件会发送给 OpenAI。

退出会停止该账户的任务、清除本地凭据并尝试撤销远程会话。对话记录和服务配置保留；继续使用该账户需重新授权。若提示远程撤销未确认，请到 ChatGPT 设置中断开此应用。

该服务由 OpenAI 提供，可能随时变更、限制或停止。授权订阅仅可在 Lyra Code 内按 ChatGPT 条款和政策使用；不得转售、共享凭据、滥用或用于被禁止的行为，否则可能导致 ChatGPT 账户受到官方警告、限制甚至停用。

## 常见问题

- **登录成功但同步不完整：** 查看同步提示，进入账号页再次同步；分别检查 Key 和模型列表。
- **退出后仍能调用模型：** 检查保留的服务配置与 Key，需要停用时手动移除。
- **余额有值但模型请求失败：** 检查模型 ID、Key 权限、平台响应与网络，见[日志](/manual/logs)。
- **New API 提示站点地址无效：** 填入完整的 `https://` 或 `http://` 地址，不要只写域名之外的路径片段。
- **New API 站点无法在应用内登录：** 站点可能要求其他登录方式，或未开放密码登录接口。
- **DeepSeek Harness 登录停在等待浏览器：** 确认系统浏览器已打开并完成授权；超时后重新发起，或关闭占用回调端口的应用。
- **DeepSeek Harness 提示已在本机退出：** 平台侧注销未完成，需要到 DeepSeek 平台断开该授权。
- **ChatGPT 用量显示暂不可用：** 在账户页尝试刷新；服务未返回、数据过期或刚重置时都可能出现此状态。
- **ChatGPT 登录成功但没有模型：** 在账户页重试同步，并检查订阅授权及 OpenAI 实际返回的错误；普通 API Key 不适用于这个账户入口。
