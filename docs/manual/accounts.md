# 第三方账号

“第三方账户”入口用于应用当前集成的梦汐 API 平台账号。普通模型服务商仍可在[模型配置](/manual/models)中手动添加，不要求登录此账号。

## 登录与注册入口

从侧栏个人资料入口，或设置中的个人资料页，找到“第三方账户 → 梦汐 API”。未登录时可登录或注册；已登录时进入账号详情。

### 登录

填写平台用户名和密码；账号启用两步验证时，继续填写验证码。应用不保存密码，登录 Cookie、用户信息和服务 Key 存在设备内。

### 注册

按页面填写用户名、密码、邮箱与邮件验证码，可填写邀请码。发送验证码和注册是否成功取决于平台状态与规则，以实际返回为准。

## 同步模型服务

登录后应用尝试同步平台 Key 与模型列表。账号页显示已配置 Key 数和模型数，可手动再次“同步”。同步可能复用或创建应用管理的 Key；它不会增加账号余额。

同步后到模型服务中核对配置、选中可用模型并发起小请求。若已有可用模型服务，账号同步不一定自动切换当前选中项。

## 额度与请求次数

账号页可刷新剩余额度、已用额度和请求次数；这些是平台返回的数据。侧栏[统计](/manual/statistics)是本地记录，两者覆盖范围与统计口径可能不同。“Key 无限额度”也仍受账号实际余额限制。

## 退出、备份与数据范围

退出会清除本地登录态并尝试注销平台会话；已配置的模型服务和 Key 保留，需要到模型服务中手动移除。账号登录态不进入应用备份或系统迁移，换设备后重新登录。模型 Key 仅在备份勾选包含密钥时导出。

账号同步不上传本地对话、附件和其他设置；使用该平台模型时，请求内容发送到该平台。页面提供平台网站入口以查看其说明。

## 常见问题

- **登录成功但同步不完整：** 查看同步提示，进入账号页再次同步；分别检查 Key 和模型列表。
- **退出后仍能调用模型：** 检查保留的服务配置与 Key，需要停用时手动移除。
- **余额有值但模型请求失败：** 检查模型 ID、Key 权限、平台响应与网络，见[日志](/manual/logs)。
