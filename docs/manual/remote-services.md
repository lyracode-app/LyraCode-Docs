# SSH 与远程文件传输

SSH 用于远程命令与终端，WebDAV 和 FTP/FTPS/SFTP 用于远程文件。先在对应服务设置中添加配置，再用只读请求测试。

## SSH

填写主机、端口、用户名与密码或密钥认证。让 AI 先列出已配置服务器，使用返回的真实 ID 执行 `pwd`，再进入项目目录。终端中的当前目录与单次远程命令的目录不能默认视为一致。

## 文件服务

| 协议 | 配置重点 | 首次验证 |
| --- | --- | --- |
| WebDAV | 基础 URL、用户名和密码/令牌 | 列目录、下载测试文件 |
| FTP / FTPS | 主机、端口、加密方式和账号 | 验证目录及 TLS 配置 |
| SFTP | SSH 认证与远程路径 | 列目录、核对身份与路径 |

FTP 明文、FTPS 与 SFTP 是不同协议，按服务支持选择。WebDAV 也可用于应用备份，操作见[备份](/manual/data)。

## 上传与下载步骤

1. 列出配置取得服务 ID，再列目标目录。
2. 核对本地工作区相对路径与远程完整路径。
3. 在测试目录上传或下载小文件。
4. 读回内容或核对大小，再处理真实文件。

服务显示名称不能代替配置 ID。覆盖前保留必要副本；网络中断后先检查目标是否已写入，再决定重试。

## 连接排查

依次检查网络端口、TLS、认证、目录权限与工具参数。保留脱敏错误码和路径，去[日志](/manual/logs)对照调用。端口连通仍不代表目标目录可写。
