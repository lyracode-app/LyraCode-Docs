# 服务选择与连接检查

先按访问方向选择服务，再进入独立配置说明。模型服务与第三方账号分别见[模型配置](/manual/models)和[第三方账号](/manual/accounts)。

## 选择服务

| 目标 | 功能 | 操作说明 |
| --- | --- | --- |
| 手机 AI 调用外部工具 | MCP 客户端 | [添加与刷新工具](/manual/mcp-client) |
| 电脑客户端调用手机工具 | MCP 服务端 | [监听、鉴权与端点](/manual/mcp-server) |
| 在电脑浏览器操作手机对话 | 网页访问 | [网页访问与项目预览](/manual/local-services) |
| 在远程机器运行命令 | SSH | [SSH 与远程文件](/manual/remote-services) |
| 上传、下载远程文件 | WebDAV、FTP/FTPS/SFTP | [文件服务](/manual/remote-services) |
| 读取与发送邮件 | IMAP、SMTP | [邮件与附件](/manual/email) |

## 配置前准备

准备真实服务地址、协议、账号/令牌与所需权限。区分显示名称和配置 ID、手机本机地址和远程主机地址；不要按名称猜工具所需的 ID。

## 连接验证顺序

### 先只读

保存并启用配置，列出工具或目录，再读取测试数据。连接成功只说明网络和协议的一部分可用，业务权限还要单独验证。

### 再测试写入

使用测试目录、测试收件人或可恢复数据，核对目标、结果与副作用。传输中断后先检查目标状态，再决定重试。

## 失败检查

按网络/端口、TLS、认证、服务权限、参数的顺序排查；MCP 再核对传输与协议。结合[日志](/manual/logs)保留脱敏错误。凭据备份范围见[数据备份](/manual/data)。
