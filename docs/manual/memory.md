# 自定义指令与记忆

把长期规则、个人偏好和本轮任务分别保存，能减少无关上下文，也方便修正错误信息。

## 选择保存位置

| 内容 | 位置 | 示例 |
| --- | --- | --- |
| 长期回答与工作规则 | 自定义指令/提示配置 | 使用中文，报告验证结果 |
| 用户确认的长期偏好 | 记忆 | 偏好最小可运行示例 |
| 项目本轮目标与临时约束 | 当前对话 | 本轮只修改 `src/` |
| 可复用任务流程 | [Skill](/manual/skills) | 项目检查清单 |

## 管理指令

在对应设置中修改规则，避免重复或相互矛盾。修改后用一个小任务验证实际回答；已有聊天记录不会被重写。临时事项直接在当前对话说明，避免长期残留。

## 管理记忆

查看现有条目，修改错误信息，停用不适用项，删除不再需要的内容。不要保存密钥、一次性任务或未经确认的敏感推断。记忆用于提供上下文，不能替代当前文件或真实工具结果。

## 示例与验证

保存“先给出最小示例，再解释”后，在新任务中请求一个小程序，核对是否按规则回答。如果项目需求与长期偏好冲突，在任务中明确本轮要求，再检查是否需要调整长期配置。

备份是否包含提示与记忆以导出选项为准，见[备份与迁移](/manual/data)。
