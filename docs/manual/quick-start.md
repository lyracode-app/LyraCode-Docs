# 完成第一个任务

本章用一个文本文件验证“模型 → 工具 → 工作区 → 结果”的完整流程。需要已安装应用、可用的模型接口，以及一个不含重要文件的空目录；无需 Termux、Linux 或 Root。

## 1. 连接模型

进入设置中的模型/服务商管理，添加接口地址、API Key 和服务商协议。填写该服务实际支持的模型 ID，并在对话中选择它。地址和模型 ID 的填写规则见[配置模型](/manual/models)。

先发送“回复一句你好”。收到回复后，再确认该模型支持工具调用，且 Agent 的文件工具处于开启状态。不要在普通消息中粘贴 API Key。

## 2. 选择工作区

新建对话，通过工作区选择入口选择一个空目录，例如共享存储中的 `LyraDemo`。在系统目录选择器中确认授权；如果使用 PRoot 内部目录，需先创建并启用 Linux 环境。

让 AI 检查目录：

> 列出当前工作区根目录，只读取，不修改文件。告诉我是否已正确选择工作区。

**成功标志：** 看到实际的目录工具调用与结果，目录为空或与预期内容一致。仅文字回答“已选择”不算验证。

## 3. 创建并读回文件

发送下面的任务：

> 在当前工作区新建 hello.txt，内容为 Hello, Lyra Code!，末尾保留换行。完成后读取文件，核对内容，并报告相对路径。

如果出现工具审批，确认目标为 `hello.txt`，再允许执行。在工具记录和文件管理器中检查文件；打开变更记录，确认只新增这个文件。

**成功标志：** 写入工具完成，随后读取返回预期文本，文件管理器能够打开 `hello.txt`。

## 4. 修改已有文件

> 将 hello.txt 中的 Hello, Lyra Code! 精确替换为 My first verified task.，读回验证，并展示差异。

查看 Diff，确认只改变这一行。若 AI 没有工具、找不到路径或请求报错，按[问题排查](/reference/troubleshooting)检查，先不要切换到更高权限工具。
