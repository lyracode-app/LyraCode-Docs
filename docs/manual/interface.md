# 界面与侧菜单栏

侧菜单栏既是任务列表，也是文件、日志、统计和归档的入口。首次使用先配置[模型](/manual/models)，再选择[工作区](/manual/workspaces)。

## 对话区域

### 输入与执行

发送前核对模型、工作区与附件。消息区展示回复、工具结果、TODO 和文件变更；输入区附近的状态用于判断正在生成、等待审批或已中断。具体操作见[对话管理](/manual/conversations)。

### 项目与历史

通过侧栏创建和选择对话，按项目整理任务；对话与项目的菜单提供重命名、置顶、归档等操作。切换项目后再次核对工作区。一个项目可以包含多段对话，它们不等于多个文件副本。

## 容易错过的操作

用户消息长按菜单、回复操作菜单中的“创建分支”见[对话分支](/manual/conversation-branches)；跳到上一轮、下一轮和最新输出见[跳转与手势](/manual/conversation-navigation)。第三方账号在个人资料相关入口，见[第三方账号](/manual/accounts)。

## 确认当前所在位置

找不到结果时，先确认选中的对话与项目，再检查当前工作区和文件路径。隐藏变更卡片、归档任务、切换文件目录分别影响不同界面，不会互相替代。
