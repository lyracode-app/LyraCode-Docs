# 预览项目与网页访问

Lyra Code 中有三种不同用途的服务。先根据目标选择，再检查服务状态和访问地址。

| 目标 | 使用方式 | 提供的内容 |
| --- | --- | --- |
| 查看工作区里的 HTML/CSS/JS | 微型服务器 | 当前配置目录中的静态文件 |
| 运行 Vite、Node 或其他开发后端 | PRoot / Termux 命令 | 由项目自己的进程提供服务 |
| 在电脑上使用手机端对话 | 网页访问 | 手机现有对话、历史、Agent 设置与上传入口 |

## 静态文件预览

1. 选择包含 `index.html` 的工作区；可先使用[完整静态示例](/examples/static-site)。
2. 在设置的微型服务器页面核对服务目录、协议、监听地址和端口。先使用 HTTP 和本机地址验证。
3. 启动服务，打开状态中报告的实际 URL，不将 `0.0.0.0` 当作浏览器目标地址。
4. 页面修改后刷新，检查请求日志与 JavaScript 错误日志。
5. 验证完成后停止服务，或确认监听范围适合继续使用。

**成功标志：** 页面显示最新内容，文件请求返回成功，按钮操作有效。404 时核对服务根目录和资源相对路径。微型服务器不执行 Node、Python 或 PHP 后端；需要后端时启动项目自身服务。

HTTPS 需要配置有效证书和私钥。浏览器的证书错误与 HTTP 请求日志是不同问题，应先完成 HTTP 本机测试再配置 HTTPS。

## 开发服务器

在正确的 Linux/Termux 项目目录安装项目依赖，运行 README 定义的开发命令。需要持续运行时使用后台模式，并记录输出文件。先在手机本机验证端口，再按需调整监听地址与局域网访问。

端口被占用时停止已知旧进程或更换端口；不要把“命令调用返回”当成页面可用。项目构建输出也可交给微型服务器预览。

## 从电脑访问手机对话

1. 在设置中打开“网页访问”，选择监听地址和端口，并确认访问码。
2. 启动后，使用电脑浏览器打开手机显示的局域网地址；电脑与手机须能互相访问。
3. 输入访问码，检查会话列表和当前对话。网页与手机共用同一个控制器，操作会影响同一份状态。
4. 保持手机端应用运行；服务会保持屏幕常亮。结束后停止网页访问。

此服务使用 HTTP。访问码用于鉴权，不能加密网络流量；仅在可信网络使用，避免直接暴露到公网。`127.0.0.1` 只接受手机本机访问，跨设备使用需选择允许局域网的监听方式。Android 局域网权限、AP 隔离或防火墙都可能影响连接。
