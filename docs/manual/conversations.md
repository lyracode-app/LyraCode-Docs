# 发送消息与管理对话

开始任务前确认模型与工作区。一段对话用于一个清晰目标，消息历史与项目文件分别保存。

## 创建与整理

从侧栏创建或选择对话，可按项目组织，使用条目菜单重命名、置顶或归档。切换项目后核对模型与目录；历史里提到的路径不等于当前工作区。[界面索引](/manual/interface)说明各入口。

## 发送一个可验证的任务

交代目标、目录、限制和验收方式，例如：

> 在当前工作区修复首页按钮无响应的问题。先读取相关文件，说明原因后修改必要内容。保留现有框架，完成后运行相关检查并报告结果。

### 执行过程中

查看生成状态、工具卡片、待确认问题与 TODO。需要补充信息时回复问题；审批前核对路径和目标。TODO 用于进度记录，完成状态仍需产物和测试支持。

### 执行结束后

核对实际文件、命令结果或预览页面。详细流程见[审批与变更审查](/manual/review)，请求异常见[日志](/manual/logs)。

## 中断与继续

停止后先检查已经完成的文件修改和外部操作。对话处于中断且没有运行任务时，可使用继续入口，从现有历史继续；先说明已完成项和接下来的目标。

后台命令或远程操作可能继续运行，停止对话不等于停止所有进程，见[后台任务](/manual/automation)。
