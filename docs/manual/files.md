# 侧栏文件与双栏管理

侧菜单栏的“文件”打开独立文件管理器，适合整理设备文件、在目录之间复制移动、打开编辑器。Agent 的项目文件访问范围由[工作区](/manual/workspaces)单独确定。

## 打开文件页

首次打开时按页面提示授予文件访问权限，再刷新目录。Android 的所有文件访问、旧版存储权限、系统目录授权是不同授权方式；某些系统目录即使授权仍有限制。

## 使用双栏

### 浏览与选择

左右两栏可进入不同目录，先选中要操作的一栏，再浏览或返回上级。核对当前路径后选择文件；批量操作前核对选中数量。

### 复制与移动

源文件在一栏，目标目录在另一栏。复制会保留源文件；移动会改变源位置。操作完成后刷新两栏，并在目标目录打开文件验证。重名或权限错误时先查看提示，避免连续重试导致误判。

### 文件菜单

按文件类型提供重命名、属性、打开方式、解压、预览 HTML 或删除等操作。删除和批量操作前核对路径，文件管理器不能代替项目版本控制。

## PRoot 与特权访问

文件页提供 PRoot 实例入口。先核对 Linux ID，避免把运行中的环境文件误当普通下载目录。需要编辑项目代码时，优先选定该实例中的项目工作区。

特权访问入口可检查 Root 或 Shizuku Shell，按设备实际授权与测试结果判断可访问范围。开启开关不代表已经获得相应系统能力。

## 打开与编辑文件

文本文件进入[代码编辑器](/manual/editor)；其他类型按可用预览或打开方式处理。HTML 静态预览见[项目预览](/manual/local-services)。文件管理器中浏览目录不会自动把它设为当前 Agent 工作区。

## 练习与排障

先创建一个测试文件，在两栏间复制，核对内容，再重命名或删除副本。若复制失败，检查目标可写性、剩余空间和系统限制；若 AI 看不到文件，重新核对会话工作区与相对路径。
