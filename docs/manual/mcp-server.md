# MCP 服务端

MCP 服务端让其他客户端通过 HTTP 调用手机上已开放的 Agent 工具。它与[连接外部 MCP](/manual/mcp-client)、[浏览器操作手机对话](/manual/local-services)是不同入口。

## 启动服务

1. 打开设置中的“本机 MCP 服务端”，配置监听地址、端口和鉴权密钥。
2. 启动后核对运行状态、端点和错误提示。默认监听配置为 `0.0.0.0:8791`，端点路径是 `/mcp`。
3. 同机客户端可访问 `127.0.0.1`；其他设备使用页面显示的手机局域网地址，两端需网络互通。

仅监听本机时填 `127.0.0.1`。`0.0.0.0` 表示监听所有 IPv4 接口，不能作为另一台设备连接手机的目标地址。页面列出的局域网地址仍需与实际监听配置和网络匹配。

## 配置外部客户端

```json
{
  "mcpServers": {
    "lyra-phone": {
      "url": "http://192.168.1.20:8791/mcp",
      "headers": { "Authorization": "Bearer REPLACE_WITH_YOUR_KEY" }
    }
  }
}
```

替换示例 IP 和密钥，按外部客户端格式导入。服务端支持 HTTP POST JSON-RPC；不能把 `GET /mcp` 当成浏览器主页或 SSE 流。客户端需支持该端点的协议协商，细节见[开发说明](/developer/mcp)。

## 验证连接

先测试状态，再从客户端获取工具列表，最后调用一个只读工具。使用桌面终端可检查状态：

```sh
curl -H "Authorization: Bearer REPLACE_WITH_YOUR_KEY" http://192.168.1.20:8791/status
```

成功应返回含 `running`、`host`、`port`、`url` 等字段的 JSON。工具调用仍需检查 `isError` 与内部结果，不能只看 HTTP 200。

## 鉴权与执行行为

密钥为空时服务端允许无密钥访问，配置远程连接前应设置密钥。当前本机服务端执行入口跳过手机对话中的逐次工具审批，因此持有访问权限的客户端应视为可信调用方；工具开关、参数校验和实际 Android 权限仍限制执行。不要以为手机一定会再次弹出确认。

服务使用 HTTP；需要跨不可信网络访问时通过可信网络或额外的加密通道部署。应用被强制停止、进程被回收或服务关闭后不能继续连接。

## 停止与排障

- **启动失败：** 检查端口占用与监听地址，修改后重启。
- **电脑无法连接：** 核对手机 IP、监听范围、同网段和网络隔离。
- **401：** 对照密钥与 Header；除 Bearer 外实现还接受 `X-Lyra-MCP-Key` 等指定密钥 Header。
- **405：** `/mcp` 需要 POST。
- **工具为空或不可用：** 检查 Agent 绑定、工具开关和依赖权限。

用完在服务端设置停止，再确认状态为已停止。
