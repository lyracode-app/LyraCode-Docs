# 归档与恢复

归档把暂时不需要的对话或项目移出日常列表，保留历史以便查找。归档数据仍保存在当前设备，备份见[备份与迁移](/manual/data)。

## 归档对话或项目

1. 在侧栏找到对话或项目，打开条目菜单。
2. 选择归档，确认条目从普通列表移出。
3. 打开侧菜单栏的“归档”，核对条目仍可找到。

项目归档会影响其下对话的展示；项目与对话分别保存归档标记，恢复项目后仍单独归档的对话需另行恢复。归档不会复制、移动或回滚项目目录中的文件，也不是后台进程的停止开关。

## 查找与恢复

### 搜索历史

归档页分别展示项目和对话，搜索框按对话标题、模型或项目名称过滤。找不到时清空搜索，并确认条目是否仍在普通列表。

### 恢复条目

使用条目的恢复操作。回到侧栏确认它已重新出现，再打开历史检查模型与工作区。迁移后目录授权或远程凭据可能需要重新配置。

## 永久删除

归档页删除操作需要确认。删除归档对话会移除其历史；删除项目会影响所属对话。需要保留的内容应先导出备份。删除会话记录不等于删除工作区文件，操作文件请查看[文件管理](/manual/files)。

## 验证示例

创建一段名为“归档测试”的对话，归档后在归档页搜索并恢复。确认消息与工作区仍在，再将同样流程用于真实任务。
