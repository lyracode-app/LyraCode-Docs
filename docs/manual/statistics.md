# 统计与 Token 用量

侧菜单栏的“统计”用于观察本地会话、请求和 Token 消耗趋势。服务商账单、[第三方账号额度](/manual/accounts)与本地统计有不同来源。

## 选择统计范围

按页面提供的日、周、月、年或全部历史切换范围，用前后按钮或日期选择查看其他时段。核对显示的起止时间，再刷新结果；简略数字与精确数字可切换。

## 指标怎么理解

| 指标 | 用途 | 注意事项 |
| --- | --- | --- |
| 会话数 | 查看任务数量 | 同一会话可能有许多请求 |
| 请求数 / 模型请求 | 判断调用频率 | 一次用户发送可触发多轮工具往返 |
| 输入 / 输出 / 总 Token | 观察上下文与生成量 | 接口计数和本地估算可能不同 |
| 用户消息 / AI 消息 / 工具结果 | 查看记录构成 | 消息条数不等于 HTTP 请求数 |
| 模型排行 | 比较模型使用分布 | 核对时间范围和模型 ID |

## 查看趋势与模型排行

展开用量、请求构成和模型卡片查看细项。比较前后时段时使用相同时间长度和数字显示方式。不要直接把总 Token 乘以某个统一价格：不同模型、缓存、推理和计费规则可能不同。

## 示例：排查突然增长

选择增长发生的时段，查看输入与输出比例以及模型排行。如果输入增长，检查长历史、附件和重复读取；如果请求数增长，结合[日志](/manual/logs)查看工具往返、失败重试和后台任务。统计只能帮助定位方向，不能单独证明原因。

## 数据边界

统计依据当前设备保存的消息、用量和请求记录。导入、删除、历史缺失或接口未返回计数都会影响结果。最终收费以服务商明细为准；备份前后应核对选中的数据范围，见[数据备份](/manual/data)。
