### Synchronization and loading

Load ten releases at a time and use Load more releases for older versions. Responses are cached in the browser for five minutes. Network errors or rate limits can fall back to clearly marked cached records; use Retry to refresh. Without a cache, visit [GitHub Releases](https://github.com/lyracode-app/Lyra-Code/releases) or the [Gitee mirror](https://gitee.com/yukisoffd/lyra-code/releases).

## Check feature availability

1. Find the installed version and build type in About.
2. Read its matching notes above to confirm the feature is included.
3. Check model capabilities, tool switches, permissions and enabled environments.
4. Collect a reproduction using the [troubleshooting checklist](/en/reference/troubleshooting) if behavior still differs.

## Documentation scope

Documentation follows application source development; the release feed represents published versions. Their update schedules can differ. Debug/Beta builds may also differ from stable releases. Compare the installed build with its release notes instead of relying on a fixed version number on this page.

The site covers [usage](/en/manual/), [application development](/en/developer/), [examples](/en/examples/) and [reference](/en/reference/). See [documentation maintenance](/en/developer/documentation).
