# Interface and sidebar

The sidebar provides task history and entries for Files, Logs, Statistics and Archive. Start by configuring a [model](/en/manual/models) and selecting a [workspace](/en/manual/workspaces).

## Conversation area

### Input and execution

Check the selected model, workspace and attachments before sending. Messages show replies, tool results, TODOs and file changes. Status indicators distinguish generation, approval and interruption. See [conversations](/en/manual/conversations).

### Projects and history

Create and select conversations from the sidebar. Conversation and project menus provide rename, pin and archive actions. Check the workspace after changing projects. Multiple conversations in a project do not create multiple copies of its files.

## Easily missed actions

The user message long-press menu and assistant reply menu offer [conversation branches](/en/manual/conversation-branches). Previous/next turn and latest-output controls are covered in [navigation and gestures](/en/manual/conversation-navigation). Account entries are described in [third-party accounts](/en/manual/accounts).

## Check your current location

When something appears missing, check the conversation, project, workspace and file path. Hiding a change card, archiving a task and browsing another directory affect separate parts of the interface.
