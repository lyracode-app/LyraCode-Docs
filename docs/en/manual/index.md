# User manual

Lyra Code is an AI development environment on Android. Models select tools, the app executes file/command/service operations, and results return to the model. Verify completion through actual files, tests or pages.

## Start here

[First task](/en/manual/quick-start) → [models](/en/manual/models) → [workspace](/en/manual/workspaces). Use the [interface/sidebar guide](/en/manual/interface) to locate controls.

### Concepts

| Concept | Meaning |
| --- | --- |
| Provider | Request endpoint, protocol and credentials |
| Conversation | Task messages, tool records and context |
| Workspace | Project directory for file tools |
| Runtime | PRoot Linux, Termux or remote command environment |

Text chat alone does not establish tool availability. Check model capabilities, tool switches, permissions and runtime separately.
