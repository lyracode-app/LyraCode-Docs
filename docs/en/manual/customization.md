# Appearance and rendering

This page covers reading appearance and rich content. See [Skills](/en/manual/skills) for reusable workflows and [instructions/memory](/en/manual/memory) for lasting rules.

## Appearance

Adjust theme, background and fonts, then check body text, code and approval cards. Inspect background masking and colors in both long conversations and code views.

## Rich content

### Markdown and formulas

Messages render headings, lists, tables, code and LaTeX. Correct rendering does not prove code or calculations; verify sources and results.

### Images, SVG and charts

Use fullscreen and export actions provided by each viewer. Static SVG does not support filters or `foreignObject`. Animated SVG uses another rendering path; scripts and external resources are not executed/loaded. Available chart export formats are shown in the menu.

## Search backend

Configure web-search backends and website blocklists. Built-in backend root domains and subdomains need separate rules. DeepSeek Search/Fetch behavior differs from the built-in blocklist; follow settings descriptions.
