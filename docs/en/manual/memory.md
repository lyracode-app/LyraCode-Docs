# Instructions and memory

Keep lasting rules, personal preferences and temporary tasks in the appropriate places so they remain relevant and easy to correct.

## Choose a location

| Content | Location | Example |
| --- | --- | --- |
| Lasting response/work rules | Custom instructions or prompt configuration | Reply in Chinese and report validation |
| Confirmed lasting preferences | Memory | Prefer minimal runnable examples |
| Current objective and constraints | Conversation | Only edit `src/` this turn |
| Reusable workflow | [Skill](/en/manual/skills) | Project review checklist |

## Manage instructions

Edit rules in their settings and remove duplication or contradictions. Verify changes with a small task; existing messages are not rewritten. Keep temporary constraints in the conversation.

## Manage memory

Review entries, correct mistakes, disable irrelevant items and delete obsolete content. Do not store keys, one-off tasks or unconfirmed sensitive inferences. Memory adds context rather than replacing current files or tool evidence.

## Example and verification

After saving “show a minimal example before explaining”, request a small program in a new task and inspect the response. State task-specific requirements when they conflict with preferences, then review whether lasting settings need changes.

Prompt and memory backup coverage depends on export selections; see [backup and migration](/en/manual/data).
