# Choose an example

These examples cover app usage and extension development. Downloadable sources are included with the site. MCP requires a real endpoint and credentials; Android runtime behavior must be checked on your device.

| Example | Prerequisites | Deliverable and success |
| --- | --- | --- |
| [Static site](/en/examples/static-site) | Selected workspace and mini server | Page opens and counter works |
| [Project repair](/en/examples/project-repair) | Existing project and relevant runnable tests | Original failure is resolved, with reviewable diff and test evidence |
| [Project-review Skill](/en/examples/skill) | Skills import and a tool-capable model | Agent reads procedure/checklist and reports findings |
| [HTTP MCP](/en/examples/mcp) | Real HTTP service and authentication | Tool listing and a read-only business call succeed |
| [API 2 pet](/en/examples/pet) | Android app with pets enabled | Status orb imports, changes color and reflects task state |

Complete [your first task](/en/manual/quick-start) before these examples. See [Extension mechanisms](/en/developer/extensions) to choose an authoring approach.
