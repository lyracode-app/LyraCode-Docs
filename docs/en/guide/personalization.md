# Chapter 7: Personalization & Themes — dress up the app to your liking

> This chapter guides you through adjusting Lyra Code's display and personalization features.
>
> Reading time: about 8 minutes.

---

## 7.1 Profile

- Set your **nickname and avatar**.
- This feature was paired with the **immersive roleplay mode** in older versions. In the new version it has no functional purpose, but it wasn't removed so you can still personalize how you appear.

## 7.2 Theme & display settings

You can configure these on the **theme page**:

- Color scheme
- Predictive back gesture
- Font & font size
- Language
- Refresh rate
- Streaming chat animation
- Chat background

| Setting | What it does | Beginner advice |
| --- | --- | --- |
| Theme mode | Light / Dark / Follow system | "Follow system" is easiest |
| Material You | Dynamic color (colors only, layout untouched) | Turn on if you like it |
| Font size | Live preview; follow system or customize | Whatever is comfortable for your eyes |
| Refresh rate | Smart / 30 / 60 / 90 / 120 Hz | Default "smart" is fine; the screen hardware decides the rest |

::: warning Dynamic color
Dynamic color (Material You) is only supported on **Android 12 and later**; changes have no effect below that version.
:::

## 7.3 System prompt

- The app ships with a **default prompt**, which normally needs no modification.
- If you need **roleplay** or other non-coding use cases, you can **add** your own prompts.
- The system prompt defines the AI's **self-identity** — expecting to get the correct model name by asking the AI "what model are you" is unrealistic.
- You can obtain the app's native prompt by reading the source code, reverse-engineering the app, or simply asking the AI.
