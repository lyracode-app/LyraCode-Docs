# Quick Start

Welcome to LyraCode Docs!

## Local development

Run these from the project root to start the local dev server:

```bash
npm install
npm run docs:dev
```

## Building the docs

Generate the static site:

```bash
npm run docs:build
```

## Preview

```bash
npm run docs:preview
```

## Automatic deployment

Pushing to the `main` branch triggers GitHub Actions to build and deploy to GitHub Pages automatically.

> Before the first deployment, choose **Source: GitHub Actions** in **Settings → Pages → Build and deployment**.
